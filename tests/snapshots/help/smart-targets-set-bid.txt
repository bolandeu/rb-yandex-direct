Usage: rb-yandex-direct smart-targets set-bid [OPTIONS]

  Установить ставку на условии таргетинга Smart-баннера.

  Example: rb-yandex-direct smart-targets set-bid --id 9001 --bid 10

Options:
  --id INTEGER                  ID условия таргетинга  [required]
  --bid FLOAT                   ставка в рублях
  --priority [LOW|NORMAL|HIGH]  приоритет для автостратегии
  -y, --yes                     без подтверждения
  --help                        Show this message and exit.
