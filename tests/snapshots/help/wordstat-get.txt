
 Usage: yd wordstat get [OPTIONS] {report_id}

 Готовый отчёт Wordstat: по каждой фразе — запросы с ней (SearchedWith) и похожие (SearchedAlso).

 --json: {"ok": true, "report_id": N, "report": [{Phrase, GeoID, SearchedWith: [{Phrase, Shows}],
 SearchedAlso: [...]}]}; Shows — число запросов за прошлый месяц.

 Example: yd wordstat get 12345 --json

╭─ Аргументы ──────────────────────────────────────────────────────────────────────────────────────╮
│ *    report_id      <int>  Id отчёта (из `wordstat create` / `wordstat list`). [обязательный]    │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Параметры ──────────────────────────────────────────────────────────────────────────────────────╮
│ --json           Машиночитаемый вывод: JSON в stdout.                                            │
│ --quiet          Не печатать ничего, кроме данных.                                               │
│ --help           Show this message and exit.                                                     │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
