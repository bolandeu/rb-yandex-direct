
 Usage: yd status [OPTIONS]

 Проект в текущей папке: имя, путь, кабинет по умолчанию, песочница.

 Нет проекта — PROJECT_NOT_INITIALIZED (exit 4); создать — `yd init`.

 Example: yd status --json

╭─ Параметры ──────────────────────────────────────────────────────────────────────────────────────╮
│ --json             Машиночитаемый вывод: JSON в stdout.                                          │
│ --quiet            Не печатать ничего, кроме данных.                                             │
│ --verbose          Подробная диагностика в stderr.                                               │
│ --help             Show this message and exit.                                                   │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
