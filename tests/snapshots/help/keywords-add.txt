Usage: yd keywords add [OPTIONS] [PHRASES]...

  Добавить ключевые фразы в группу (до 1000 за вызов).

  Example: yd keywords add --adgroup 555 'купить диван' 'диван недорого' --search-bid 15

Options:
  --adgroup INTEGER             группа, куда добавлять  [required]
  --from-file PATH              файл с фразами построчно (альтернатива positional args)
  --search-bid FLOAT            ставка поиска в рублях для всех добавляемых фраз
  --network-bid FLOAT           ставка сетей в рублях
  --priority [HIGH|NORMAL|LOW]  StrategyPriority для авто-стратегии
  -y, --yes                     без подтверждения
  --help                        Show this message and exit.
