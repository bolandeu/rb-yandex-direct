
 Usage: yd keywords add [OPTIONS] [phrases]...

 Добавить ключевые фразы в группу (до 1000 за вызов); ставки — в рублях.

 Автотаргетинг — `--autotargeting-phrase` с настройками `--autotargeting Exact=YES …`.

 Example: yd keywords add 'купить диван' 'диван недорого' --adgroup 555 --search-bid 15 --dry-run

╭─ Аргументы ──────────────────────────────────────────────────────────────────────────────────────╮
│   phrases      <str>  Фразы (или --from-file).                                                   │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Параметры ──────────────────────────────────────────────────────────────────────────────────────╮
│ *  --adgroup                     <int>              Группа объявлений, куда добавить фразы.      │
│                                                     [обязательный]                               │
│    --from-file                   <str>              Файл с фразами, по одной в строке.           │
│    --search-bid                  <float>            Ставка на поиске, ₽ (ручная стратегия).      │
│    --network-bid                 <float>            Ставка в сетях, ₽ (ручная стратегия).        │
│    --priority                    <LOW|NORMAL|HIGH>  Приоритет для автостратегии: LOW, NORMAL,    │
│                                                     HIGH.                                        │
│    --user-param1                 <str>              Значение {param1} для подстановки в ссылку.  │
│    --user-param2                 <str>              Значение {param2} для подстановки в ссылку.  │
│    --autotargeting-phrase                           Добавить и фразу автотаргетинга              │
│                                                     (---autotargeting).                          │
│    --autotargeting               <str>              Настройка автотаргетинга NAME=YES|NO         │
│                                                     (повторяемая): Exact, Narrow, Alternative,   │
│                                                     Accessory, Broader, WithoutBrands,           │
│                                                     WithAdvertiserBrand, WithCompetitorsBrand.   │
│                                                     Применяется только к фразе автотаргетинга.   │
│    --confirm                                        Подтвердить изменение в кабинете без вопроса │
│                                                     (обязательно вместе с --non-interactive).    │
│    --dry-run                                        Показать, что будет сделано, ничего не       │
│                                                     меняя.                                       │
│    --non-interactive                                Никогда не спрашивать; при нехватке данных — │
│                                                     ошибка.                                      │
│    --json                                           Машиночитаемый вывод: JSON в stdout.         │
│    --quiet                                          Не печатать ничего, кроме данных.            │
│    --help                                           Show this message and exit.                  │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
