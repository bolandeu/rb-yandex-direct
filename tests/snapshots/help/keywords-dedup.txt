
 Usage: yd keywords dedup [OPTIONS] [phrases]...

 Подсказать, какие фразы склеить и какие минус-слова добавить, чтобы фразы не пересекались.

 Только расчёт (keywordsresearch.deduplicate): кабинет не меняется, применять — `keywords
 add/update/delete`. --json: {"ok": true, "result": {Add: [{Keyword}], Update: [{Id, Keyword}],
 Delete: {Ids}, Failure: [...]}}.

 Example: yd keywords dedup 'купить диван' 'купить диван недорого' --json

╭─ Аргументы ──────────────────────────────────────────────────────────────────────────────────────╮
│   phrases      <str>  Фразы (или --from-file, или --adgroup).                                    │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Параметры ──────────────────────────────────────────────────────────────────────────────────────╮
│ --from-file        <str>                                  Файл с фразами, по одной в строке.     │
│ --adgroup          <int>                                  Взять фразы этих групп (с их Id) —     │
│                                                           проверка дублей в кабинете             │
│                                                           (повторяемая).                         │
│ --operation        <MERGE_DUPLICATES|ELIMINATE_OVERLAPPI  MERGE_DUPLICATES — склеить дубли,      │
│                    NG>                                    ELIMINATE_OVERLAPPING — минусовать     │
│                                                           пересечения (по умолчанию обе).        │
│ --json                                                    Машиночитаемый вывод: JSON в stdout.   │
│ --quiet                                                   Не печатать ничего, кроме данных.      │
│ --help                                                    Show this message and exit.            │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
