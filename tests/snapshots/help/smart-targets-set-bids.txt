
 Usage: yd smart-targets set-bids [OPTIONS]

 Задать средние цены клика/конверсии или приоритет фильтрам (ровно одно из --id, --adgroup,
 --campaign).

 Example: yd smart-targets set-bids --id 9001 --average-cpc 12 --dry-run

╭─ Параметры ──────────────────────────────────────────────────────────────────────────────────────╮
│ --id                     <int>              Id условия.                                          │
│ --adgroup                <int>              Id группы — для всех её условий.                     │
│ --campaign               <int>              Id кампании — для всех её условий.                   │
│ --average-cpc            <float>            Средняя цена клика, ₽ (стратегия с оплатой за        │
│                                             клики).                                              │
│ --average-cpa            <float>            Средняя цена конверсии, ₽ (стратегия с оплатой за    │
│                                             конверсии).                                          │
│ --priority               <LOW|NORMAL|HIGH>  Приоритет для автостратегии: LOW, NORMAL, HIGH.      │
│ --confirm                                   Подтвердить изменение в кабинете без вопроса         │
│                                             (обязательно вместе с --non-interactive).            │
│ --dry-run                                   Показать, что будет сделано, ничего не меняя.        │
│ --non-interactive                           Никогда не спрашивать; при нехватке данных — ошибка. │
│ --json                                      Машиночитаемый вывод: JSON в stdout.                 │
│ --quiet                                     Не печатать ничего, кроме данных.                    │
│ --help                                      Show this message and exit.                          │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
