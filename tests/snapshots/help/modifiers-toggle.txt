Usage: yd modifiers toggle [OPTIONS]

  Включить/выключить корректировки группы/кампании по типу.

  Example: yd modifiers toggle --campaign 12345 --type DEMOGRAPHICS_ADJUSTMENT --enabled NO

Options:
  --campaign INTEGER              ID кампании
  --adgroup INTEGER               ID группы объявлений
  --type [DEMOGRAPHICS_ADJUSTMENT|RETARGETING_ADJUSTMENT|REGIONAL_ADJUSTMENT|SERP_LAYOUT_ADJUSTMENT|INCOME_GRADE_ADJUSTMENT]
                                  тип корректировки  [required]
  --enabled [YES|NO]              YES — включить, NO — выключить  [required]
  -y, --yes                       без подтверждения
  --help                          Show this message and exit.
