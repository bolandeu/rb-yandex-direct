
 Usage: yd masters [OPTIONS] COMMAND [ARGS]...

 Мастер кампаний (веб-интерфейс, без API): список, статусы, создание, правка, изображения. Нужен
 extra `browser` и сессия Яндекса (`yd browser login` или вход в Chrome).

╭─ Параметры ──────────────────────────────────────────────────────────────────────────────────────╮
│ --help          Show this message and exit.                                                      │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Commands ───────────────────────────────────────────────────────────────────────────────────────╮
│ list            Кампании Мастера из общей таблицы кампаний кабинета, в котором вы вошли в        │
│                 браузере.                                                                        │
│ get             Одна кампания Мастера: название, статус, ссылка, плитки статистики (для          │
│                 черновика — поля формы).                                                         │
│ audience        Аудитория кампании: пол, возраст, устройства, интересы и поисковые запросы (теги │
│                 по порядку).                                                                     │
│ counters        Счётчики Яндекс Метрики кампании (раздел есть только при цели «максимум          │
│                 конверсий»).                                                                     │
│ target-actions  Целевые действия (цели Метрики) кампании и цены за них — Id целей для            │
│                 `update`/`add`.                                                                  │
│ suspend         Остановить кампанию Мастера (статус проверяется после клика).                    │
│ resume          Возобновить остановленную кампанию Мастера.                                      │
│ archive         Архивировать кампанию Мастера (через меню строки в таблице кампаний).            │
│ delete          Удалить кампанию Мастера — необратимо; Яндекс даёт удалить только кампании без   │
│                 показов.                                                                         │
│ launch          Отправить черновик Мастера на модерацию (запуск) — начнутся показы и траты.      │
│ copy            Скопировать кампанию Мастера; результат содержит Id новой кампании.              │
│ add             Создать кампанию Мастера («Конверсии и трафик») — экспериментально, заполняет    │
│                 форму в браузере.                                                                │
│ update          Изменить кампанию Мастера: бюджет, цели, тексты, изображения, аудиторию, ссылки  │
│                 — экспериментально.                                                              │
│ images          Изображения Мастера кампаний: список, добавить, удалить, заменить набор.         │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
