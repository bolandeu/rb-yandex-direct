
 Usage: yd tags banners [OPTIONS]

 Какие метки назначены объявлениям (GetBannersTags): по кампаниям или по Id объявлений.

 --json: {"ok": true, "count": N, "banners": [{BannerID, TagIDS: [...]}]}.

 Example: yd tags banners --banner 777 --json

╭─ Параметры ──────────────────────────────────────────────────────────────────────────────────────╮
│ --campaign        <int>  Все объявления этих кампаний (повторяемая).                             │
│ --banner          <int>  Эти объявления (повторяемая).                                           │
│ --json                   Машиночитаемый вывод: JSON в stdout.                                    │
│ --quiet                  Не печатать ничего, кроме данных.                                       │
│ --help                   Show this message and exit.                                             │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
