
 Usage: yd ads get [OPTIONS] {ad_id}

 Одно объявление со всеми полями его типа (TextAd, ResponsiveAd, MobileAppAd…).

 --json: {"ok": true, "ad": {...}}; нет такого объявления — INVALID_ARGUMENTS.

 Example: yd ads get 777 --json

╭─ Аргументы ──────────────────────────────────────────────────────────────────────────────────────╮
│ *    ad_id      <int>  Id объявления. [обязательный]                                             │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Параметры ──────────────────────────────────────────────────────────────────────────────────────╮
│ --json           Машиночитаемый вывод: JSON в stdout.                                            │
│ --quiet          Не печатать ничего, кроме данных.                                               │
│ --help           Show this message and exit.                                                     │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
