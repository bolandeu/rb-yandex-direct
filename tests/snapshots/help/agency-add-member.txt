
 Usage: yd agency add-member [OPTIONS] {organization_login}

 Пригласить сотрудника в организацию клиента (agencyclients.addPassportOrganizationMember).

 Нужен --invite-email и/или --invite-phone.

 Example: yd agency add-member romashka-org --role ADMIN --invite-email boss@romashka.ru --dry-run

╭─ Аргументы ──────────────────────────────────────────────────────────────────────────────────────╮
│ *    organization_login      <str>  Логин организации клиента (из add-organization).             │
│                                     [обязательный]                                               │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Параметры ──────────────────────────────────────────────────────────────────────────────────────╮
│ --role                   <str>  Роль в организации: ADMIN или USER. [по умолчанию: USER]         │
│ --invite-email           <str>  Куда отправить приглашение: email.                               │
│ --invite-phone           <str>  Куда отправить приглашение: телефон.                             │
│ --confirm                       Подтвердить изменение в кабинете без вопроса (обязательно вместе │
│                                 с --non-interactive).                                            │
│ --dry-run                       Показать, что будет сделано, ничего не меняя.                    │
│ --non-interactive               Никогда не спрашивать; при нехватке данных — ошибка.             │
│ --json                          Машиночитаемый вывод: JSON в stdout.                             │
│ --quiet                         Не печатать ничего, кроме данных.                                │
│ --help                          Show this message and exit.                                      │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
