
 Usage: yd audiences set-bids [OPTIONS]

 Задать ставку в сетях или приоритет нацеливаниям на аудитории.

 Ровно одно из --id, --adgroup, --campaign.

 Example: yd audiences set-bids --id 5001 --context-bid 8 --dry-run

╭─ Параметры ──────────────────────────────────────────────────────────────────────────────────────╮
│ --id                     <int>              Id нацеливания.                                      │
│ --adgroup                <int>              Id группы — для всех её нацеливаний.                 │
│ --campaign               <int>              Id кампании — для всех её нацеливаний.               │
│ --context-bid            <float>            Ставка в сетях, ₽.                                   │
│ --priority               <LOW|NORMAL|HIGH>  Приоритет для автостратегии: LOW, NORMAL, HIGH.      │
│ --confirm                                   Подтвердить изменение в кабинете без вопроса         │
│                                             (обязательно вместе с --non-interactive).            │
│ --dry-run                                   Показать, что будет сделано, ничего не меняя.        │
│ --non-interactive                           Никогда не спрашивать; при нехватке данных — ошибка. │
│ --json                                      Машиночитаемый вывод: JSON в stdout.                 │
│ --quiet                                     Не печатать ничего, кроме данных.                    │
│ --help                                      Show this message and exit.                          │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
