Usage: rb-yandex-direct images [OPTIONS] [COMMAND] [ARGS]...

  Изображения для объявлений (adimages).

Options:
  --help  Show this message and exit.

Commands:
  add     Загрузить изображения из файлов (до 100, рекомендуется ≤3).
  delete  Удалить изображения по хэшам.
  list    Изображения, загруженные в кабинет.
