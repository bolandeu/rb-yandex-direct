Usage: rb-yandex-direct audiences add [OPTIONS]

  Привязать аудиторию к группе объявлений.

  Example: rb-yandex-direct audiences add --adgroup 555 --retargeting 4001

Options:
  --adgroup INTEGER             ID группы объявлений  [required]
  --retargeting INTEGER         ID списка ретаргетинга (или используй --interest)
  --interest INTEGER            ID интереса (только для MOBILE_APP_AD_GROUP)
  --context-bid FLOAT           ставка в сетях в рублях (ручная стратегия)
  --priority [LOW|NORMAL|HIGH]  StrategyPriority для авто-стратегий
  -y, --yes                     без подтверждения
  --help                        Show this message and exit.
