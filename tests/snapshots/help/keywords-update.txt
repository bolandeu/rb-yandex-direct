
 Usage: yd keywords update [OPTIONS] {keyword_id}

 Изменить текст фразы, параметры подстановки или настройки автотаргетинга.

 Ставки и приоритет меняет `bids set`.

 Example: yd keywords update 901 --keyword 'купить угловой диван' --dry-run

╭─ Аргументы ──────────────────────────────────────────────────────────────────────────────────────╮
│ *    keyword_id      <int>  Id ключевой фразы. [обязательный]                                    │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Параметры ──────────────────────────────────────────────────────────────────────────────────────╮
│ --keyword                <str>  Новый текст фразы.                                               │
│ --user-param1            <str>  Значение {param1}; пустая строка — очистить.                     │
│ --user-param2            <str>  Значение {param2}; пустая строка — очистить.                     │
│ --autotargeting          <str>  Настройка автотаргетинга NAME=YES|NO (повторяемая): Exact,       │
│                                 Narrow, Alternative, Accessory, Broader, WithoutBrands,          │
│                                 WithAdvertiserBrand, WithCompetitorsBrand. Применяется только к  │
│                                 фразе автотаргетинга.                                            │
│ --confirm                       Подтвердить изменение в кабинете без вопроса (обязательно вместе │
│                                 с --non-interactive).                                            │
│ --dry-run                       Показать, что будет сделано, ничего не меняя.                    │
│ --non-interactive               Никогда не спрашивать; при нехватке данных — ошибка.             │
│ --json                          Машиночитаемый вывод: JSON в stdout.                             │
│ --quiet                         Не печатать ничего, кроме данных.                                │
│ --help                          Show this message and exit.                                      │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
