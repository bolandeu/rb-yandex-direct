Usage: yd retargeting [OPTIONS] [COMMAND] [ARGS]...

  Списки ретаргетинга (цели/аудитории Метрики).

Options:
  --help  Show this message and exit.

Commands:
  add     Создать список ретаргетинга из одного набора целей.
  delete  Удалить списки ретаргетинга.
  list    Списки ретаргетинга и аудиторий.
  update  Обновить имя/описание списка ретаргетинга.
