Usage: rb-yandex-direct adgroups add [OPTIONS]

  Создать текстовую группу объявлений.

  Example: rb-yandex-direct adgroups add --campaign 12345 --name 'Диваны' --region 213

Options:
  --campaign INTEGER       ID кампании  [required]
  --name TEXT              имя группы  [required]
  --region INTEGER         ID регионов для таргетинга (0 = вся Россия)  [required]
  --negative-keyword TEXT  минус-фразы на уровне группы (повторяй флаг)
  -y, --yes                без подтверждения
  --help                   Show this message and exit.
