Usage: rb-yandex-direct modifiers list [OPTIONS]

  Корректировки ставок кампаний и групп.

  Example: rb-yandex-direct modifiers list --campaign 12345

Options:
  --campaign INTEGER              фильтр по кампании (можно несколько раз)
  --adgroup INTEGER               фильтр по группе объявлений (можно несколько раз)
  --type [MOBILE_ADJUSTMENT|DEMOGRAPHICS_ADJUSTMENT|RETARGETING_ADJUSTMENT|REGIONAL_ADJUSTMENT|VIDEO_ADJUSTMENT|INCOME_GRADE_ADJUSTMENT]
                                  фильтр по типу корректировки (можно несколько раз)
  --output PATH                   сохранить JSON в файл
  --help                          Show this message and exit.
