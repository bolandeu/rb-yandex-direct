Usage: rb-yandex-direct feeds add-json [OPTIONS]

  Создать фиды из JSON-файла (структура — как в feeds.add).

  Example: rb-yandex-direct feeds add-json --from-json feeds.json

Options:
  --from-json PATH  JSON-файл со структурой для API (формат — как в документации метода)  [required]
  -y, --yes         без подтверждения
  --help            Show this message and exit.
