Usage: rb-yandex-direct ads moderation [OPTIONS]

  Объявления, ждущие модерации или отклонённые.

  Example: rb-yandex-direct ads moderation --campaign 12345

Options:
  --campaign INTEGER  фильтр по кампании (можно несколько раз)
  --output PATH       сохранить JSON в файл
  --help              Show this message and exit.
