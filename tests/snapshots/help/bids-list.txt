Usage: rb-yandex-direct bids list [OPTIONS]

  Ставки по ключевым фразам (нужен хотя бы один фильтр).

  Example: rb-yandex-direct bids list --campaign 12345

Options:
  --keyword INTEGER   фильтр по ключевой фразе (можно несколько раз)
  --adgroup INTEGER   фильтр по группе объявлений (можно несколько раз)
  --campaign INTEGER  фильтр по кампании (можно несколько раз)
  --output PATH       сохранить JSON в файл
  --help              Show this message and exit.
