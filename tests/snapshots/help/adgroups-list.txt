Usage: rb-yandex-direct adgroups list [OPTIONS]

  Список групп объявлений (фильтр по кампаниям и типам).

  Example: rb-yandex-direct adgroups list --campaign 12345

Options:
  --campaign INTEGER  фильтр по кампании (можно несколько раз)
  --type TEXT         TEXT_AD_GROUP, DYNAMIC_TEXT_AD_GROUP, ...
  --output PATH       сохранить JSON в файл
  --help              Show this message and exit.
