
 Usage: yd retargeting update [OPTIONS] {list_id}

 Изменить название, описание или правила условия; с --goal правила целиком заменяются одним новым.

 Example: yd retargeting update 4001 --name 'Корзина 30 дней' --dry-run

╭─ Аргументы ──────────────────────────────────────────────────────────────────────────────────────╮
│ *    list_id      <int>  Id условия ретаргетинга. [обязательный]                                 │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Параметры ──────────────────────────────────────────────────────────────────────────────────────╮
│ --name                   <str>           Новое название.                                         │
│ --description            <str>           Новое описание.                                         │
│ --goal                   <int>           Id цели или сегмента Метрики (повторяемая).             │
│ --days                   <int>           Срок, за который учитывается достижение цели, 1–540     │
│                                          дней.                                                   │
│                                          [по умолчанию: 30]                                      │
│ --operator               <ALL|ANY|NONE>  Как сочетать цели правила: ALL — все, ANY — любая, NONE │
│                                          — ни одной.                                             │
│                                          [по умолчанию: ANY]                                     │
│ --confirm                                Подтвердить изменение в кабинете без вопроса            │
│                                          (обязательно вместе с --non-interactive).               │
│ --dry-run                                Показать, что будет сделано, ничего не меняя.           │
│ --non-interactive                        Никогда не спрашивать; при нехватке данных — ошибка.    │
│ --json                                   Машиночитаемый вывод: JSON в stdout.                    │
│ --quiet                                  Не печатать ничего, кроме данных.                       │
│ --help                                   Show this message and exit.                             │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
