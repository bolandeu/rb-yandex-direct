
 Usage: yd masters add [OPTIONS] {url}

 Создать кампанию Мастера («Конверсии и трафик») — экспериментально, заполняет форму в браузере.

 Яндекс не сохранит форму без цели Метрики и недельного бюджета: цели берутся из счётчика,
 найденного по домену сайта (`masters target-actions` у похожей кампании покажет Id).
 Песочницы и отката у Мастера нет — сначала --dry-run.

 Example: yd masters add https://example.com/ --headline 'Заголовок' --text 'Текст' --region Москва
 --target-action 236386933=150 --weekly-budget 5000 --draft --dry-run

╭─ Аргументы ──────────────────────────────────────────────────────────────────────────────────────╮
│ *    url      <str>  Продвигаемый сайт (посадочная страница). [обязательный]                     │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Параметры ──────────────────────────────────────────────────────────────────────────────────────╮
│ *  --headline               <str>  Заголовок (повторяемая, до 5). [обязательный]                 │
│ *  --text                   <str>  Текст объявления (повторяемая, до 3). [обязательный]          │
│    --region                 <str>  Регион по названию, как в интерфейсе (повторяемая).           │
│    --region-id              <int>  Регион по Id справочника Директа (повторяемая; нужен токен    │
│                                    API).                                                         │
│ *  --target-action          <str>  Цель Метрики и цена: "ID_цели=цена" (повторяемая; хотя бы     │
│                                    одна).                                                        │
│                                    [обязательный]                                                │
│ *  --weekly-budget          <int>  Недельный бюджет в валюте кабинета. [обязательный]            │
│    --draft                         Сохранить черновиком, не отправляя на модерацию.              │
│    --confirm                       Подтвердить изменение в кабинете без вопроса (обязательно     │
│                                    вместе с --non-interactive).                                  │
│    --dry-run                       Показать, что будет сделано, ничего не меняя.                 │
│    --non-interactive               Никогда не спрашивать; при нехватке данных — ошибка.          │
│    --headful                       Показать окно браузера (отладка, капча).                      │
│    --chrome-dir             <str>  Папка профилей Chrome (user-data-dir): всегда свежие куки     │
│                                    оттуда, без сохранённой сессии.                               │
│    --chrome-profile         <str>  Профиль Chrome внутри --chrome-dir. [по умолчанию: Default]   │
│    --json                          Машиночитаемый вывод: JSON в stdout.                          │
│    --quiet                         Не печатать ничего, кроме данных.                             │
│    --help                          Show this message and exit.                                   │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
