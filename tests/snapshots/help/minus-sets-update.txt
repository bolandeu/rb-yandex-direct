Usage: rb-yandex-direct minus-sets update [OPTIONS] SET_ID

  Обновить набор минус-слов (целиком заменяет фразы).

  Example: rb-yandex-direct minus-sets update 6001 --from-file minus.txt

Options:
  --name TEXT       новое имя набора
  --words TEXT      полный список минус-фраз через запятую (заменяет текущие)
  --from-file PATH  файл с фразами по строкам
  -y, --yes         без подтверждения
  --help            Show this message and exit.
