
 Usage: yd bids set-auto [OPTIONS]

 Однократно рассчитать и выставить ставки по правилу: объём трафика на поиске или охват в сетях.

 Ровно одно из --keyword, --adgroup, --campaign и одно из --target-traffic-volume,
 --target-coverage. Приоритет автостратегии — `bids set --priority`.

 Example: yd bids set-auto --campaign 12345 --target-traffic-volume 75 --bid-ceiling 40 --dry-run

╭─ Параметры ──────────────────────────────────────────────────────────────────────────────────────╮
│ --keyword                      <int>    Id фразы (или автотаргетинга).                           │
│ --adgroup                      <int>    Id группы — для всех её фраз.                            │
│ --campaign                     <int>    Id кампании — для всех её фраз.                          │
│ --target-traffic-volume        <int>    Поиск: целевой объём трафика, 5–100 (100 — как у первого │
│                                         места).                                                  │
│ --target-coverage              <int>    Сети: целевой охват аудитории, 1–100 %.                  │
│ --increase-percent             <int>    Надбавка к рассчитанной ставке, 0–1000 %.                │
│ --bid-ceiling                  <float>  Максимальная ставка, ₽.                                  │
│ --confirm                               Подтвердить изменение в кабинете без вопроса             │
│                                         (обязательно вместе с --non-interactive).                │
│ --dry-run                               Показать, что будет сделано, ничего не меняя.            │
│ --non-interactive                       Никогда не спрашивать; при нехватке данных — ошибка.     │
│ --json                                  Машиночитаемый вывод: JSON в stdout.                     │
│ --quiet                                 Не печатать ничего, кроме данных.                        │
│ --help                                  Show this message and exit.                              │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
