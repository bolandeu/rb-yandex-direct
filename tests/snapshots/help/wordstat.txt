
 Usage: yd wordstat [OPTIONS] COMMAND [ARGS]...

 Wordstat через API Директа v4: отчёты о поисковых запросах (create/list/get/delete, run — всё
 сразу).

╭─ Параметры ──────────────────────────────────────────────────────────────────────────────────────╮
│ --help          Show this message and exit.                                                      │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Commands ───────────────────────────────────────────────────────────────────────────────────────╮
│ create  Запустить формирование отчёта Wordstat (CreateNewWordstatReport); вернуть его Id.        │
│ list    Отчёты Wordstat на сервере (до пяти) и их статус: Done, Pending, Failed.                 │
│ get     Готовый отчёт Wordstat: по каждой фразе — запросы с ней (SearchedWith) и похожие         │
│         (SearchedAlso).                                                                          │
│ delete  Удалить отчёт Wordstat с сервера — освободить место (их не больше пяти; сами удаляются   │
│         через 5 часов).                                                                          │
│ run     Всё сразу: создать отчёт, дождаться готовности, получить и удалить с сервера.            │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
