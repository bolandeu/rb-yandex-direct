Usage: yd campaigns set-negative-keywords [OPTIONS] CAMPAIGN_ID

  Заменить минус-слова на уровне кампании (полный список заменяет текущий).

  Example: yd campaigns set-negative-keywords 12345 --words 'бесплатно,скачать'

Options:
  --type [TextCampaign|DynamicTextCampaign|UnifiedCampaign|SmartCampaign|MobileAppCampaign|McBannerCampaign|CpmBannerCampaign|CpmVideoCampaign|CpmPriceCampaign|ContentPromotionCampaign]
                                  тип кампании
  --words TEXT                    минус-фразы через запятую
  --from-file PATH                файл с фразами построчно
  -y, --yes                       без подтверждения
  --help                          Show this message and exit.
