Usage: yd report queries [OPTIONS]

  SEARCH_QUERY_PERFORMANCE_REPORT: реальные поисковые запросы пользователей.

  Example: yd report queries --date-from 2026-09-01 --date-to 2026-09-27 --campaign 12345

Options:
  --date-from TEXT    начало периода, YYYY-MM-DD  [required]
  --date-to TEXT      конец периода, YYYY-MM-DD  [required]
  --campaign INTEGER  фильтр по кампании (можно несколько раз)
  -o, --output PATH   сохранить строки отчёта в JSON-файл
  --help              Show this message and exit.
