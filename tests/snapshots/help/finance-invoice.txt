
 Usage: yd finance invoice [OPTIONS]

 ДЕНЬГИ: выставить счёт на оплату кампаний (CreateInvoice); вернуть ссылку на счёт.

 Суммы — в валюте, с НДС клиента. Нужен мастер-токен.

 Example: yd finance invoice --pay 12345=5000 --dry-run

╭─ Параметры ──────────────────────────────────────────────────────────────────────────────────────╮
│ *  --pay                    <str>  Кампания и сумма в валюте: CAMPAIGN_ID=СУММА (повторяемая).   │
│                                    [обязательный]                                                │
│    --currency               <str>  Валюта сумм: RUB, BYN, KZT, TRY, UAH, USD, EUR, CHF.          │
│                                    [по умолчанию: RUB]                                           │
│    --confirm                       Подтвердить изменение в кабинете без вопроса (обязательно     │
│                                    вместе с --non-interactive).                                  │
│    --dry-run                       Показать, что будет сделано, ничего не меняя.                 │
│    --non-interactive               Никогда не спрашивать; при нехватке данных — ошибка.          │
│    --json                          Машиночитаемый вывод: JSON в stdout.                          │
│    --quiet                         Не печатать ничего, кроме данных.                             │
│    --help                          Show this message and exit.                                   │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
