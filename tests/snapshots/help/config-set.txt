
 Usage: yd config set [OPTIONS] {key} {value}

 Изменить одну настройку проекта (не секрет: токены — только `auth login`).

 Example: yd config set direct.login shop@yandex.ru

╭─ Аргументы ──────────────────────────────────────────────────────────────────────────────────────╮
│ *    key        <str>  Ключ через точку, например direct.login (см. `config list`).              │
│                        [обязательный]                                                            │
│ *    value      <str>  Новое значение (true/false — для direct.sandbox). [обязательный]          │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Параметры ──────────────────────────────────────────────────────────────────────────────────────╮
│ --json           Машиночитаемый вывод: JSON в stdout.                                            │
│ --quiet          Не печатать ничего, кроме данных.                                               │
│ --help           Show this message and exit.                                                     │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
