
 Usage: yd forecast [OPTIONS] COMMAND [ARGS]...

 Прогноз бюджета через API Директа v4: показы, клики, цены клика по фразам.

╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Commands ───────────────────────────────────────────────────────────────────────────────────────╮

│ list    Прогнозы на сервере (до пяти) и их статус: Done, Pending, Failed.                        │
