
 Usage: yd creatives add-video-extension [OPTIONS] {video_ids}...

 Создать видеодополнения (VideoExtensionCreative) из загруженных видео.

 Id креативов из ответа указываются в `ads add-text --video-extension`.

 Example: yd creatives add-video-extension 5f1a2b3c --confirm

╭─ Аргументы ──────────────────────────────────────────────────────────────────────────────────────╮
│ *    video_ids      <str>  Id видео из `videos add`, до 10 за вызов. [обязательный]              │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Параметры ──────────────────────────────────────────────────────────────────────────────────────╮
│ --confirm                  Подтвердить изменение в кабинете без вопроса (обязательно вместе с    │
│                            --non-interactive).                                                   │
│ --dry-run                  Показать, что будет сделано, ничего не меняя.                         │
│ --non-interactive          Никогда не спрашивать; при нехватке данных — ошибка.                  │
│ --json                     Машиночитаемый вывод: JSON в stdout.                                  │
│ --quiet                    Не печатать ничего, кроме данных.                                     │
│ --help                     Show this message and exit.                                           │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
