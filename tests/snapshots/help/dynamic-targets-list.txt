
 Usage: yd dynamic-targets list [OPTIONS]

 Условия нацеливания по страницам сайта: условия, ставки, состояние.

 Нужен хотя бы один из --id, --adgroup, --campaign.
 --json: {"ok": true, "count": N, "targets": [{Id, AdGroupId, CampaignId, Name, State, Bid,
 ContextBid, StrategyPriority, Conditions: [{Operand, Operator, Arguments}], ConditionType}]}.

 Example: yd dynamic-targets list --campaign 12345

╭─ Параметры ──────────────────────────────────────────────────────────────────────────────────────╮
│ --id              <int>                       Только эти Id (повторяемая).                       │
│ --adgroup         <int>                       Фильтр по группе объявлений (повторяемая).         │
│ --campaign        <int>                       Фильтр по кампании (повторяемая).                  │
│ --state           <ON|OFF|SUSPENDED|DELETED>  ON, OFF, SUSPENDED, DELETED (повторяемая).         │
│ --field           <str>                       Поле FieldNames вместо набора по умолчанию         │
│                                               (повторяемая).                                     │
│ --json                                        Машиночитаемый вывод: JSON в stdout.               │
│ --quiet                                       Не печатать ничего, кроме данных.                  │
│ --help                                        Show this message and exit.                        │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
