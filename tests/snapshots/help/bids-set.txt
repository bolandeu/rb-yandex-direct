
 Usage: yd bids set [OPTIONS]

 Задать ставку (ручная стратегия) или приоритет (автостратегия) фразе, группе или кампании.

 Ровно одно из --keyword, --adgroup, --campaign; ставки — в рублях.

 Example: yd bids set --keyword 901 --search-bid 12.5 --dry-run

╭─ Параметры ──────────────────────────────────────────────────────────────────────────────────────╮
│ --keyword                                 <int>              Id фразы (или автотаргетинга).      │
│ --adgroup                                 <int>              Id группы — для всех её фраз.       │
│ --campaign                                <int>              Id кампании — для всех её фраз.     │
│ --search-bid                              <float>            Ставка на поиске, ₽.                │
│ --network-bid                             <float>            Ставка в сетях, ₽.                  │
│ --autotargeting-search-bid-is-auto        <YES|NO>           YES — ставка автотаргетинга на      │
│                                                              поиске подбирается сама.            │
│ --priority                                <LOW|NORMAL|HIGH>  Приоритет для автостратегии: LOW,   │
│                                                              NORMAL, HIGH.                       │
│ --confirm                                                    Подтвердить изменение в кабинете    │
│                                                              без вопроса (обязательно вместе с   │
│                                                              --non-interactive).                 │
│ --dry-run                                                    Показать, что будет сделано, ничего │
│                                                              не меняя.                           │
│ --non-interactive                                            Никогда не спрашивать; при нехватке │
│                                                              данных — ошибка.                    │
│ --json                                                       Машиночитаемый вывод: JSON в        │
│                                                              stdout.                             │
│ --quiet                                                      Не печатать ничего, кроме данных.   │
│ --help                                                       Show this message and exit.         │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
