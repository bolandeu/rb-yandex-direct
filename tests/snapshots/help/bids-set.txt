Usage: yd bids set [OPTIONS]

  Установить ручную ставку по ключу. Ставки задаются в рублях — домножаются на 1e6.

  Example: yd bids set --keyword 901 --search-bid 12.5

Options:
  --keyword INTEGER    ID ключевой фразы  [required]
  --search-bid FLOAT   ставка на поиске (в рублях)
  --network-bid FLOAT  ставка в сетях (в рублях)
  -y, --yes            без подтверждения
  --help               Show this message and exit.
