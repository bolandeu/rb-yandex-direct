
 Usage: yd images add [OPTIONS] {paths}...

 Загрузить изображения из файлов; хэши из ответа привязываются к объявлениям (--image-hash).

 --dry-run показывает запрос без содержимого файлов (размер в байтах вместо base64).
 --json: отчёт изменения; хэши — в result.AddResults[].AdImageHash.

 Example: yd images add banner.png --confirm

╭─ Аргументы ──────────────────────────────────────────────────────────────────────────────────────╮
│ *    paths      <str>  Файлы изображений (JPG, PNG, GIF), до 100 за вызов. [обязательный]        │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Параметры ──────────────────────────────────────────────────────────────────────────────────────╮
│ --type                   <AUTO|REGULAR|WIDE|FIXED_IMAGE>  Тип изображения; AUTO — по размерам.   │
│                                                           [по умолчанию: AUTO]                   │
│ --confirm                                                 Подтвердить изменение в кабинете без   │
│                                                           вопроса (обязательно вместе с          │
│                                                           --non-interactive).                    │
│ --dry-run                                                 Показать, что будет сделано, ничего не │
│                                                           меняя.                                 │
│ --non-interactive                                         Никогда не спрашивать; при нехватке    │
│                                                           данных — ошибка.                       │
│ --json                                                    Машиночитаемый вывод: JSON в stdout.   │
│ --quiet                                                   Не печатать ничего, кроме данных.      │
│ --help                                                    Show this message and exit.            │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
