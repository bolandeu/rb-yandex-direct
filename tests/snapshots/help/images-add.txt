Usage: rb-yandex-direct images add [OPTIONS] PATHS...

  Загрузить изображения из файлов (до 100, рекомендуется ≤3).

  Example: rb-yandex-direct images add banner.png

Options:
  --type [REGULAR|WIDE|FIXED_IMAGE|AUTO]
                                  тип изображения (AUTO — по размеру файла)
  -y, --yes                       без подтверждения
  --help                          Show this message and exit.
