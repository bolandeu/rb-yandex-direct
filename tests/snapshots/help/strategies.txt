
 Usage: yd strategies [OPTIONS] COMMAND [ARGS]...

 Пакетные стратегии: список, создание, изменение, архив (сервис Strategies).

╭─ Параметры ──────────────────────────────────────────────────────────────────────────────────────╮
│ --help          Show this message and exit.                                                      │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Команды ────────────────────────────────────────────────────────────────────────────────────────╮
│ list       Пакетные стратегии кабинета со всеми параметрами (бюджет, цель, цена конверсии).      │
│ add        Создать пакетную стратегию; кампании подключаются к ней через PackageBiddingStrategy. │
│ update     Изменить пакетную стратегию: название, параметры, счётчики, цели, атрибуцию.          │
│ archive    Отправить пакетные стратегии в архив (к ним больше нельзя подключать кампании).       │
│ unarchive  Вернуть пакетные стратегии из архива.                                                 │
│ add-json   Создать пакетные стратегии из JSON: список StrategyAddItem или {"Strategies": [...]}. │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
