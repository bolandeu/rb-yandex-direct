Usage: yd modifiers [OPTIONS] [COMMAND] [ARGS]...

  Корректировки ставок (устройства, регионы, демо, ретаргетинг).

Options:
  --help  Show this message and exit.

Commands:
  add     Добавить корректировку ставки.
  delete  Удалить корректировки ставок.
  list    Корректировки ставок кампаний и групп.
  set     Изменить значение существующей корректировки.
  toggle  Включить/выключить корректировки группы/кампании по типу.
