
 Usage: yd history get [OPTIONS]

 Журнал изменений кабинета, новые сверху; фильтры применяет сам Директ.

 Без --date-from/--date-to — период раздела по умолчанию. В Event — поля события целиком,
 в том числе oldStrategy/newStrategy: какая цель или счётчик пропали из стратегии.
 --json: {"ok": true, "count": N, "history": [...]}.

 Example: yd history get --campaign 12345 --date-from 2026-09-01 --json

╭─ Параметры ──────────────────────────────────────────────────────────────────────────────────────╮
│ --campaign              <int>  Только записи этих кампаний (повторяемая).                        │
│ --date-from             <str>  Начало периода: YYYY-MM-DD или YYYY-MM-DDTHH:MM:SS.               │
│ --date-to               <str>  Конец периода: YYYY-MM-DD или YYYY-MM-DDTHH:MM:SS.                │
│ --by                    <str>  Только изменения этих логинов (повторяемая).                      │
│ --source                <str>  Источник изменения: WEB, API, OTHER… (повторяемая).               │
│ --category              <str>  Категория изменения, например CAMPAIGN_STRATEGY (повторяемая; по  │
│                                умолчанию все).                                                   │
│ --limit                 <int>  Не больше N записей (по умолчанию все).                           │
│ --headful                      Показать окно браузера (отладка, капча).                          │
│ --chrome-dir            <str>  Папка профилей Chrome (user-data-dir): всегда свежие куки оттуда, │
│                                без сохранённой сессии.                                           │
│ --chrome-profile        <str>  Профиль Chrome внутри --chrome-dir. [по умолчанию: Default]       │
│ --json                         Машиночитаемый вывод: JSON в stdout.                              │
│ --quiet                        Не печатать ничего, кроме данных.                                 │
│ --help                         Show this message and exit.                                       │
