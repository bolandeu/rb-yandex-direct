
 Usage: yd retargeting add [OPTIONS]

 Создать условие ретаргетинга из одного правила (набор целей с оператором).

 Несколько правил — `retargeting add-json`.

 Example: yd retargeting add --name Корзина --goal 123456 --days 30 --dry-run

╭─ Параметры ──────────────────────────────────────────────────────────────────────────────────────╮
│ *  --name                   <str>                   Название (до 250 символов). [обязательный]   │
│    --goal                   <int>                   Id цели или сегмента Метрики (повторяемая).  │
│    --days                   <int>                   Срок, за который учитывается достижение      │
│                                                     цели, 1–540 дней.                            │
│                                                     [по умолчанию: 30]                           │
│    --operator               <ALL|ANY|NONE>          Как сочетать цели правила: ALL — все, ANY —  │
│                                                     любая, NONE — ни одной.                      │
│                                                     [по умолчанию: ANY]                          │
│    --description            <str>                   Описание (до 4096 символов).                 │
│    --type                   <RETARGETING|AUDIENCE>  RETARGETING или AUDIENCE.                    │
│                                                     [по умолчанию: RETARGETING]                  │
│    --confirm                                        Подтвердить изменение в кабинете без вопроса │
│                                                     (обязательно вместе с --non-interactive).    │
│    --dry-run                                        Показать, что будет сделано, ничего не       │
│                                                     меняя.                                       │
│    --non-interactive                                Никогда не спрашивать; при нехватке данных — │
│                                                     ошибка.                                      │
│    --json                                           Машиночитаемый вывод: JSON в stdout.         │
│    --quiet                                          Не печатать ничего, кроме данных.            │
│    --help                                           Show this message and exit.                  │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
