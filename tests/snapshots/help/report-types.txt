
 Usage: yd report types [OPTIONS]

 Типы отчётов и готовые периоды (--range), которые принимает `report custom` (без запроса к API).

 Example: yd report types --json

╭─ Параметры ──────────────────────────────────────────────────────────────────────────────────────╮
│ --json           Машиночитаемый вывод: JSON в stdout.                                            │
│ --quiet          Не печатать ничего, кроме данных.                                               │
│ --help           Show this message and exit.                                                     │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
