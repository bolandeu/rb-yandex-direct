
 Usage: yd finance transfer [OPTIONS]

 ДЕНЬГИ: перевести деньги между кампаниями (TransferMoney); суммы «откуда» и «куда» равны.

 Доступную сумму кампании показывает Директ (SumAvailableForTransfer). Нужен мастер-токен.

 Example: yd finance transfer --from 111=1000 --to 222=1000 --dry-run

╭─ Параметры ──────────────────────────────────────────────────────────────────────────────────────╮
│ *  --from                   <str>  Откуда: CAMPAIGN_ID=СУММА (повторяемая). [обязательный]       │
│ *  --to                     <str>  Куда: CAMPAIGN_ID=СУММА (повторяемая). [обязательный]         │
│    --currency               <str>  Валюта сумм: RUB, BYN, KZT, TRY, UAH, USD, EUR, CHF.          │
│                                    [по умолчанию: RUB]                                           │
│    --confirm                       Подтвердить изменение в кабинете без вопроса (обязательно     │
│                                    вместе с --non-interactive).                                  │
│    --dry-run                       Показать, что будет сделано, ничего не меняя.                 │
│    --non-interactive               Никогда не спрашивать; при нехватке данных — ошибка.          │
│    --json                          Машиночитаемый вывод: JSON в stdout.                          │
│    --quiet                         Не печатать ничего, кроме данных.                             │
│    --help                          Show this message and exit.                                   │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
