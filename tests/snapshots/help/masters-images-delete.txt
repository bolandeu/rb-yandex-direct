
 Usage: yd masters images delete [OPTIONS] {campaign_id}

 Удалить изображения кампании Мастера по позиции, content id или все — экспериментально.

 Example: yd masters images delete 72349978 --position 2 --dry-run

╭─ Аргументы ──────────────────────────────────────────────────────────────────────────────────────╮
│ *    campaign_id      <int>  Id кампании Мастера (как в интерфейсе Директа). [обязательный]      │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Параметры ──────────────────────────────────────────────────────────────────────────────────────╮
│ --position               <int>  Позиция с 1 из `masters images list` (повторяемая).              │
│ --content-id             <str>  Content id изображения (повторяемая).                            │
│ --all                           Удалить все изображения.                                         │
│ --launch                        После сохранения отправить на модерацию.                         │
│ --confirm                       Подтвердить изменение в кабинете без вопроса (обязательно вместе │
│                                 с --non-interactive).                                            │
│ --dry-run                       Показать, что будет сделано, ничего не меняя.                    │
│ --non-interactive               Никогда не спрашивать; при нехватке данных — ошибка.             │
│ --headful                       Показать окно браузера (отладка, капча).                         │
│ --chrome-dir             <str>  Папка профилей Chrome (user-data-dir): всегда свежие куки        │
│                                 оттуда, без сохранённой сессии.                                  │
│ --chrome-profile         <str>  Профиль Chrome внутри --chrome-dir. [по умолчанию: Default]      │
│ --json                          Машиночитаемый вывод: JSON в stdout.                             │
│ --quiet                         Не печатать ничего, кроме данных.                                │
│ --help                          Show this message and exit.                                      │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
