
 Usage: yd vcards list [OPTIONS]

 Визитки кабинета: адрес, телефон, время работы.

 --json: {"ok": true, "count": N, "vcards": [{Id, CampaignId, Country, City, CompanyName, WorkTime,
 Phone, …}]}.

 Example: yd vcards list --campaign 12345

╭─ Параметры ──────────────────────────────────────────────────────────────────────────────────────╮
│ --id              <int>  Только эти визитки (повторяемая).                                       │
│ --campaign        <int>  Визитки этих кампаний (повторяемая; отбор после ответа API — API        │
│                          фильтрует только по Id).                                                │
│ --json                   Машиночитаемый вывод: JSON в stdout.                                    │
│ --quiet                  Не печатать ничего, кроме данных.                                       │
│ --help                   Show this message and exit.                                             │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
