
 Usage: yd ads [OPTIONS] COMMAND [ARGS]...

 Объявления: список, создание по типам, изменение, модерация, статусы, удаление.

╭─ Параметры ──────────────────────────────────────────────────────────────────────────────────────╮
│ --help          Show this message and exit.                                                      │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Команды ────────────────────────────────────────────────────────────────────────────────────────╮
│ list            Список объявлений с фильтрами; поля TextAd (заголовок, текст, ссылка) — по       │
│                 умолчанию.                                                                       │
│ get             Одно объявление со всеми полями его типа (TextAd, ResponsiveAd, MobileAppAd…).   │
│ moderation      Объявления, не прошедшие модерацию до конца: черновики, на модерации и           │
│                 отклонённые.                                                                     │
│ moderate        Отправить черновики объявлений на модерацию.                                     │
│ suspend         Остановить показы объявлений.                                                    │
│ resume          Возобновить показы остановленных объявлений.                                     │
│ archive         Архивировать объявления.                                                         │
│ unarchive       Вернуть объявления из архива.                                                    │
│ delete          Удалить объявления — необратимо; удаляются только черновики и объявления без     │
│                 показов.                                                                         │
│ add-text        Создать текстово-графическое объявление (TextAd).                                │
│ add-responsive  Создать адаптивное объявление (ResponsiveAd): Директ сам комбинирует заголовки,  │
│                 тексты и картинки.                                                               │
│ add-mobile-app  Создать объявление мобильного приложения (MobileAppAd).                          │
│ add-image       Создать графическое объявление из изображения (TextImageAd).                     │
│ add-builder     Создать графическое объявление из креатива конструктора (TextAdBuilderAd).       │
│ add-shopping    Создать товарное объявление по фиду (ShoppingAd, с --listing — ListingAd).       │
│ update          Изменить текстовое объявление (TextAd); после изменения оно снова уходит на      │
│                 модерацию.                                                                       │
│ add-json        Создать объявления из JSON: список AdAddItem или {"Ads": [...]} — любой тип, до  │
│                 1000 за вызов.                                                                   │
│ update-json     Изменить объявления из JSON: список AdUpdateItem (Id + один блок типа) или       │
│                 {"Ads": [...]}.                                                                  │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
