Usage: yd creatives list [OPTIONS]

  Креативы (HTML5, видео, смарт-баннеры).

  Example: yd creatives list --type VIDEO_EXTENSION_CREATIVE

Options:
  --type [IMAGE_CREATIVE|HTML5_CREATIVE|VIDEO_EXTENSION_CREATIVE|CPC_VIDEO_CREATIVE|CPM_VIDEO_CREATIVE|SMART_CREATIVE]
                                  фильтр по типу креатива (можно несколько раз)
  --output PATH                   сохранить JSON в файл
  --help                          Show this message and exit.
