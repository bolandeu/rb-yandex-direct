
 Usage: yd vcards add [OPTIONS]

 Создать визитку; Id из ответа — для `ads add-text --vcard`.

 Example: yd vcards add --campaign 12345 --country Россия --city Москва --company Ромашка
 --work-time '0#4#9#00#18#00' --phone-country-code +7 --phone-city-code 495 --phone-number 1234567
 --dry-run

╭─ Параметры ──────────────────────────────────────────────────────────────────────────────────────╮
│ *  --campaign                  <int>  Id кампании. [обязательный]                                │
│ *  --country                   <str>  Страна. [обязательный]                                     │
│ *  --city                      <str>  Город. [обязательный]                                      │
│ *  --company                   <str>  Название организации. [обязательный]                       │
│ *  --work-time                 <str>  Время работы в формате API:                                │
│                                       'день_с#день_по#час#мин#час#мин', например 0#4#9#00#18#00. │
│                                       [обязательный]                                             │
│ *  --phone-country-code        <str>  Код страны, например +7. [обязательный]                    │
│ *  --phone-city-code           <str>  Код города или оператора, например 495. [обязательный]     │
│ *  --phone-number              <str>  Номер телефона. [обязательный]                             │
│    --phone-extension           <str>  Добавочный номер.                                          │
│    --street                    <str>  Улица.                                                     │
│    --house                     <str>  Дом.                                                       │
│    --building                  <str>  Корпус или строение.                                       │
│    --apartment                 <str>  Офис или квартира.                                         │
│    --contact-person            <str>  Контактное лицо.                                           │
│    --email                     <str>  Email.                                                     │
│    --extra-message             <str>  Подробнее о товаре или услуге.                             │
│    --ogrn                      <str>  ОГРН организации.                                          │
│    --metro                     <int>  Id станции метро (справочник регионов).                    │
│    --messenger                 <str>  Мессенджер 'клиент|логин', например 'telegram|shop'.       │
│    --confirm                          Подтвердить изменение в кабинете без вопроса (обязательно  │
│                                       вместе с --non-interactive).                               │
│    --dry-run                          Показать, что будет сделано, ничего не меняя.              │
│    --non-interactive                  Никогда не спрашивать; при нехватке данных — ошибка.       │
│    --json                             Машиночитаемый вывод: JSON в stdout.                       │
│    --quiet                            Не печатать ничего, кроме данных.                          │
│    --help                             Show this message and exit.                                │
