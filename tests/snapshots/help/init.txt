
 Usage: yd init [OPTIONS]

 Создать проект клиента: .yd/config.toml в текущей папке (или --project).

 В проекте задаётся кабинет по умолчанию: `--login` и YANDEX_DIRECT_LOGIN важнее него.
 Проект необязателен — без него команды работают со своим кабинетом.

 Example: yd init --name shop --client-login shop@yandex.ru

╭─ Параметры ──────────────────────────────────────────────────────────────────────────────────────╮
│ --name                <str>  Имя проекта (по умолчанию — имя папки).                             │
│ --force                      Перезаписать конфиг уже созданного проекта.                         │
│ --client-login        <str>  Client-Login кабинета клиента: команды в этой папке пойдут в него.  │
│ --sandbox                    Работать в песочнице API по умолчанию.                              │
│ --json                       Машиночитаемый вывод: JSON в stdout.                                │
│ --quiet                      Не печатать ничего, кроме данных.                                   │
│ --verbose                    Подробная диагностика в stderr.                                     │
│ --help                       Show this message and exit.                                         │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
