
 Usage: yd shared-account enable [OPTIONS] {client_login}

 ДЕНЬГИ: подключить клиенту общий счёт — деньги всех кампаний переносятся на него
 (EnableSharedAccount).

 Только для агентств; необратимо; у клиента должна быть хотя бы одна кампания.

 Example: yd shared-account enable shop-login --dry-run

╭─ Аргументы ──────────────────────────────────────────────────────────────────────────────────────╮
│ *    client_login      <str>  Логин клиента агентства. [обязательный]                            │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Параметры ──────────────────────────────────────────────────────────────────────────────────────╮
│ --confirm                  Подтвердить изменение в кабинете без вопроса (обязательно вместе с    │
│                            --non-interactive).                                                   │
│ --dry-run                  Показать, что будет сделано, ничего не меняя.                         │
│ --non-interactive          Никогда не спрашивать; при нехватке данных — ошибка.                  │
│ --json                     Машиночитаемый вывод: JSON в stdout.                                  │
