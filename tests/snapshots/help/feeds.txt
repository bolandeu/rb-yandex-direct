
 Usage: yd feeds [OPTIONS] COMMAND [ARGS]...

 Товарные фиды: список, создание по ссылке или файлом, изменение, удаление.

╭─ Параметры ──────────────────────────────────────────────────────────────────────────────────────╮
│ --help          Show this message and exit.                                                      │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Commands ───────────────────────────────────────────────────────────────────────────────────────╮
│ list         Товарные фиды кабинета: источник, статус обработки, число товаров, кампании.        │
│ add          Добавить фид по ссылке (--url) или файлом (--file).                                 │
│ update       Изменить фид: название, ссылку и её авторизацию, UTM, или загрузить новый файл.     │
│ delete       Удалить фиды — необратимо; фид, к которому привязаны кампании, API не удалит.       │
│ add-json     Добавить фиды из JSON: список FeedAddItem или {"Feeds": [...]}.                     │
│ update-json  Изменить фиды из JSON: список FeedUpdateItem (с Id) или {"Feeds": [...]}.           │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
