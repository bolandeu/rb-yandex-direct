
 Usage: yd finance pay [OPTIONS]

 ДЕНЬГИ: оплатить кампании из кредита агентства или овердрафта (PayCampaigns).

 Сразу пополняет баланс кампаний и создаёт обязательство оплатить счёт. Нужен мастер-токен.

 Example: yd finance pay --pay 12345=5000 --method Overdraft --dry-run

╭─ Параметры ──────────────────────────────────────────────────────────────────────────────────────╮
│ *  --pay                    <str>             Кампания и сумма в валюте: CAMPAIGN_ID=СУММА       │
│                                               (повторяемая).                                     │
│                                               [обязательный]                                     │
│ *  --method                 <Bank|Overdraft>  Bank — из кредитного лимита агентства (нужен       │
│                                               --contract), Overdraft — овердрафт.                │
│                                               [обязательный]                                     │
│    --contract               <str>             Номер договора (для --method Bank).                │
│    --currency               <str>             Валюта сумм: RUB, BYN, KZT, TRY, UAH, USD, EUR,    │
│                                               CHF.                                               │
│                                               [по умолчанию: RUB]                                │
│    --confirm                                  Подтвердить изменение в кабинете без вопроса       │
│                                               (обязательно вместе с --non-interactive).          │
│    --dry-run                                  Показать, что будет сделано, ничего не меняя.      │
│    --non-interactive                          Никогда не спрашивать; при нехватке данных —       │
│                                               ошибка.                                            │
│    --json                                     Машиночитаемый вывод: JSON в stdout.               │
│    --quiet                                    Не печатать ничего, кроме данных.                  │
│    --help                                     Show this message and exit.                        │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
