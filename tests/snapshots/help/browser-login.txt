
 Usage: yd browser login [OPTIONS]

 Сохранить сессию Яндекса для `masters` и `history`.

 По умолчанию открывает окно Chromium со своим профилем — войдите в Яндекс руками один раз,
 дальше куки живут в профиле (работает на macOS, Linux и Windows, без keychain).
 --from-chrome — без окна: расшифровать куки Яндекса из вашего Chrome (на macOS один раз
 спросит доступ к keychain) и сохранить снимок. С --non-interactive доступен только --from-chrome.

 Example: yd browser login --from-chrome

╭─ Параметры ──────────────────────────────────────────────────────────────────────────────────────╮
│ --from-chrome                   Не открывать окно: сохранить куки Яндекса из вашего Chrome.      │
│ --no-verify                     С --from-chrome: не проверять куки открытием Директа (сеть с     │
│                                 капчей).                                                         │
│ --timeout                <int>  Сколько секунд ждать ручного входа в окне. [по умолчанию: 300]   │
│ --chrome-dir             <str>  Папка профилей Chrome (user-data-dir): всегда свежие куки        │
│                                 оттуда, без сохранённой сессии.                                  │
│ --chrome-profile         <str>  Профиль Chrome внутри --chrome-dir. [по умолчанию: Default]      │
│ --non-interactive               Никогда не спрашивать; при нехватке данных — ошибка.             │
│ --json                          Машиночитаемый вывод: JSON в stdout.                             │
│ --quiet                         Не печатать ничего, кроме данных.                                │
│ --help                          Show this message and exit.                                      │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
