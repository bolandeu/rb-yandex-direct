
 Usage: yd wordstat create [OPTIONS] {phrases}...

 Запустить формирование отчёта Wordstat (CreateNewWordstatReport); вернуть его Id.

 Отчёт готовится до минуты: статус — `wordstat list`, данные — `wordstat get`.
 Расходует баллы API. --json: {"ok": true, "report_id": N}.

 Example: yd wordstat create 'купить диван' 'диван недорого' -r 213

╭─ Аргументы ──────────────────────────────────────────────────────────────────────────────────────╮
│ *    phrases      <str>  Ключевые фразы (до 10), можно с минус-словами: 'диван -кожаный'.        │
│                          [обязательный]                                                          │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Параметры ──────────────────────────────────────────────────────────────────────────────────────╮
│ --region  -r      <int>  Id региона (повторяемая); минус — исключить: -r 1 -r -219. Нет — все    │
│                          регионы.                                                                │
│ --json                   Машиночитаемый вывод: JSON в stdout.                                    │
│ --quiet                  Не печатать ничего, кроме данных.                                       │
│ --help                   Show this message and exit.                                             │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
