Usage: yd report campaigns [OPTIONS]

  CAMPAIGN_PERFORMANCE_REPORT: эффективность кампаний.

  Example: yd report campaigns --date-from 2026-09-01 --date-to 2026-09-27

Options:
  --date-from TEXT   начало периода, YYYY-MM-DD  [required]
  --date-to TEXT     конец периода, YYYY-MM-DD  [required]
  -o, --output PATH  сохранить строки отчёта в JSON-файл
  --help             Show this message and exit.
