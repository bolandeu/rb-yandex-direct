
 Usage: yd report campaigns [OPTIONS]

 Эффективность кампаний по дням: показы, клики, расход, CTR, CPC, конверсии, отказы.

 --json: {"ok": true, "report_type", "report_name", "request_id", "count": N, "rows": [{Поле:
 значение}]};
 числа — числами, `--` API — null, деньги — в рублях (--micros — в микроединицах).
 --dry-run печатает запрос к API без выполнения.

 Example: yd report campaigns --date-from 2026-09-01 --date-to 2026-09-27

│                                    AYS|LAST_90_DAYS|LAST_365_DAY  LAST_30_DAYS).                 │
│                                    S|THIS_WEEK_MON_TODAY|THIS_WE                                 │

│                                    T|THIS_MONTH|LAST_MONTH|ALL_T                                 │
