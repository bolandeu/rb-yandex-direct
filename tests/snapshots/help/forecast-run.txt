
 Usage: yd forecast run [OPTIONS] {phrases}...

 Всё сразу: создать прогноз, дождаться готовности, получить и удалить с сервера.

 --json — как у `forecast get`.

 Example: yd forecast run 'купить диван' -r 213 --json

╭─ Аргументы ──────────────────────────────────────────────────────────────────────────────────────╮
│ *    phrases      <str>  Ключевые фразы (до 100). [обязательный]                                 │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Параметры ──────────────────────────────────────────────────────────────────────────────────────╮
│ --region        -r      <int>    Id региона (повторяемая); минус — исключить.                    │
│ --currency              <str>    Валюта сумм: RUB, BYN, KZT, TRY, UAH, USD, EUR, CHF.            │
│                                  [по умолчанию: RUB]                                             │
│ --minus-word    -m      <str>    Минус-слово для всех фраз (повторяемая).                        │
│ --auction-bids                   Добавить ставки аукциона по позициям (AuctionBids=Yes).         │
│ --timeout               <float>  Сколько секунд ждать готовности прогноза. [по умолчанию: 120.0] │
│ --keep                           Не удалять прогноз с сервера после получения.                   │
│ --json                           Машиночитаемый вывод: JSON в stdout.                            │
│ --quiet                          Не печатать ничего, кроме данных.                               │
│ --help                           Show this message and exit.                                     │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
