
 Usage: yd changes dictionaries [OPTIONS] [timestamp]

 Менялись ли справочники регионов, часовых поясов и интересов с момента времени.

 --json: {"ok": true, "changes": {RegionsChanged, TimeZonesChanged, InterestsChanged, Timestamp}}.

 Example: yd changes dictionaries 2026-09-01T00:00:00Z

╭─ Аргументы ──────────────────────────────────────────────────────────────────────────────────────╮
│   timestamp      <str>  Момент времени UTC, ISO 8601; без него — только текущий Timestamp.       │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Параметры ──────────────────────────────────────────────────────────────────────────────────────╮
│ --json           Машиночитаемый вывод: JSON в stdout.                                            │
│ --quiet          Не печатать ничего, кроме данных.                                               │
│ --help           Show this message and exit.                                                     │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
