
 Usage: yd tags set-campaign [OPTIONS] {campaign_id}

 Задать полный список меток кампании (UpdateCampaignsTags): не перечисленные — удаляются.

 Существующие метки сохраняют Id (и назначения объявлениям), новые создаются.

 Example: yd tags set-campaign 12345 -t распродажа -t зима --dry-run

╭─ Аргументы ──────────────────────────────────────────────────────────────────────────────────────╮
│ *    campaign_id      <int>  Id кампании. [обязательный]                                         │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Параметры ──────────────────────────────────────────────────────────────────────────────────────╮
│ --tag              -t      <str>  Метка (повторяемая); нет ни одной — удалить все.               │
│ --confirm                         Подтвердить изменение в кабинете без вопроса (обязательно      │
│                                   вместе с --non-interactive).                                   │
│ --dry-run                         Показать, что будет сделано, ничего не меняя.                  │
│ --non-interactive                 Никогда не спрашивать; при нехватке данных — ошибка.           │
│ --json                            Машиночитаемый вывод: JSON в stdout.                           │
│ --quiet                           Не печатать ничего, кроме данных.                              │
│ --help                            Show this message and exit.                                    │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
