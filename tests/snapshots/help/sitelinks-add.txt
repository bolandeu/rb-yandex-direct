
 Usage: yd sitelinks add [OPTIONS]

 Создать набор быстрых ссылок; Id набора из ответа — для `ads add-text --sitelink-set`.

 Наборы не редактируются: для правки создайте новый и привяжите к объявлениям.

 Example: yd sitelinks add --link 'Доставка|https://example.com/d' --link
 'Оплата|https://example.com/p|Картой и наличными' --dry-run

╭─ Параметры ──────────────────────────────────────────────────────────────────────────────────────╮
│ *  --link                   <str>  Ссылка 'Заголовок|https://…[|Описание]' (повторяемая, 1–8     │
│                                    шт.).                                                         │
│                                    [обязательный]                                                │
│    --confirm                       Подтвердить изменение в кабинете без вопроса (обязательно     │
│                                    вместе с --non-interactive).                                  │
│    --dry-run                       Показать, что будет сделано, ничего не меняя.                 │
│    --non-interactive               Никогда не спрашивать; при нехватке данных — ошибка.          │
│    --json                          Машиночитаемый вывод: JSON в stdout.                          │
│    --quiet                         Не печатать ничего, кроме данных.                             │
│    --help                          Show this message and exit.                                   │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
