
 Usage: yd shared-account transfer [OPTIONS]

 ДЕНЬГИ: перевести деньги между общими счетами (AccountManagement TransferMoney).

 Не больше 3 переводов в сутки с одного счёта. Нужен мастер-токен.

 Example: yd shared-account transfer --from 555 --to 556 --amount 1000 --dry-run

╭─ Параметры ──────────────────────────────────────────────────────────────────────────────────────╮
│ *  --from                   <int>    Id общего счёта-источника. [обязательный]                   │
│ *  --to                     <int>    Id общего счёта-получателя. [обязательный]                  │
│ *  --amount                 <float>  Сумма в валюте счёта. [обязательный]                        │
│    --currency               <str>    Валюта сумм: RUB, BYN, KZT, TRY, UAH, USD, EUR, CHF.        │
│                                      [по умолчанию: RUB]                                         │
│    --confirm                         Подтвердить изменение в кабинете без вопроса (обязательно   │
│                                      вместе с --non-interactive).                                │
│    --dry-run                         Показать, что будет сделано, ничего не меняя.               │
│    --non-interactive                 Никогда не спрашивать; при нехватке данных — ошибка.        │
│    --json                            Машиночитаемый вывод: JSON в stdout.                        │
│    --quiet                           Не печатать ничего, кроме данных.                           │
│    --help                            Show this message and exit.                                 │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
