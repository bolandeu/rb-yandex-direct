
 Usage: yd events list [OPTIONS]

 Записи журнала событий за период: модерация, зачисления, остановки по бюджету и др.

 Денежные значения — в валюте --currency (не в микроединицах).
 --json: {"ok": true, "count": N, "events": [{Timestamp, EventName, EventType, CampaignID,
 BannerID, PhraseID, AccountID, TextDescription, Attributes}]}.

 Example: yd events list --from 2026-09-01 --campaign 12345 --json

╭─ Параметры ──────────────────────────────────────────────────────────────────────────────────────╮
│ *  --from             <str>  С какого момента, ISO 8601: 2026-09-01 или 2026-09-01T00:00:00Z.    │
│                              [обязательный]                                                      │
│    --to               <str>  По какой момент, ISO 8601; нет — по текущий.                        │
│    --currency         <str>  Валюта сумм: RUB, BYN, KZT, TRY, UAH, USD, EUR, CHF.                │
│                              [по умолчанию: RUB]                                                 │
│    --campaign         <int>  Только эти кампании (повторяемая).                                  │
│    --banner           <int>  Только эти объявления (повторяемая).                                │
│    --phrase           <int>  Только эти фразы (повторяемая).                                     │
│    --account          <int>  Только эти общие счета (повторяемая).                               │
│    --type             <str>  Тип события: MoneyIn, MoneyOut, BannerModerated, CampaignFinished…  │
│                              (повторяемая).                                                      │
│    --client           <str>  Логин клиента агентства (повторяемая).                              │
│    --last-only               Только последняя запись по каждому типу событий.                    │
│    --limit            <int>  Сколько записей вернуть.                                            │
│    --offset           <int>  Сколько записей пропустить.                                         │
│    --json                    Машиночитаемый вывод: JSON в stdout.                                │
│    --quiet                   Не печатать ничего, кроме данных.                                   │
│    --help                    Show this message and exit.                                         │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
