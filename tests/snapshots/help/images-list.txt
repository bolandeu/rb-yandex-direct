
 Usage: yd images list [OPTIONS]

 Изображения, загруженные в кабинет.

 --json: {"ok": true, "count": N, "images": [{AdImageHash, Name, Type, Subtype, Associated,
 PreviewUrl, OriginalUrl}]}.

 Example: yd images list --associated NO --json

╭─ Параметры ──────────────────────────────────────────────────────────────────────────────────────╮
│ --hash              <str>     Только эти изображения (повторяемая).                              │
│ --associated        <YES|NO>  YES — привязанные к объявлениям, NO — свободные.                   │
│ --json                        Машиночитаемый вывод: JSON в stdout.                               │
│ --quiet                       Не печатать ничего, кроме данных.                                  │
│ --help                        Show this message and exit.                                        │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
