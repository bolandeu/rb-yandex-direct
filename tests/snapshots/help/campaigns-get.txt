
 Usage: yd campaigns get [OPTIONS] {campaign_id}

 Одна кампания по Id: общие поля (набор как у `campaigns list`).

 --json: {"ok": true, "campaign": {...}}; нет такой кампании — INVALID_ARGUMENTS.

 Example: yd campaigns get 12345 --json

╭─ Аргументы ──────────────────────────────────────────────────────────────────────────────────────╮
│ *    campaign_id      <int>  Id кампании. [обязательный]                                         │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Параметры ──────────────────────────────────────────────────────────────────────────────────────╮
│ --json           Машиночитаемый вывод: JSON в stdout.                                            │
│ --quiet          Не печатать ничего, кроме данных.                                               │
│ --help           Show this message and exit.                                                     │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
