
 Usage: yd minus-sets list [OPTIONS]

 Наборы минус-фраз: название, фразы, подключён ли к группам.

 --json: {"ok": true, "count": N, "sets": [{Id, Name, NegativeKeywords: [...], Associated}]}.

 Example: yd minus-sets list --json

│ --json                Машиночитаемый вывод: JSON в stdout.                                       │
│ --quiet               Не печатать ничего, кроме данных.                                          │
