
 Usage: yd smart-targets update [OPTIONS] {target_id}

 Изменить фильтр смарт-баннеров: название, аудиторию, условия, цены, приоритет.

 Example: yd smart-targets update 9001 --average-cpa 300 --dry-run

╭─ Аргументы ──────────────────────────────────────────────────────────────────────────────────────╮
│ *    target_id      <int>  Id фильтра. [обязательный]                                            │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Параметры ──────────────────────────────────────────────────────────────────────────────────────╮
│ --name                        <str>                             Новое название.                  │
│ --audience                    <INTERESTED_IN_SIMILAR_PRODUCTS|  Новая аудитория.                 │
│                               VISITED_PRODUCT_PAGE|ALL_SEGMENT                                   │
│                               S>                                                                 │
│ --condition                   <str>                             Условие по полю фида             │
│                                                                 OPERAND:OPERATOR:ARG1|ARG2       │
│                                                                 (повторяемая), например          │
│                                                                 categoryId:EQUALS_ANY:12|15;     │
│                                                                 OPERATOR — EQUALS_ANY,           │
│                                                                 NOT_EQUALS_ALL, CONTAINS_ANY,    │
│                                                                 NOT_CONTAINS_ALL, GREATER_THAN,  │
│                                                                 LESS_THAN, IN_RANGE. Без условий │
│                                                                 — все товары. Заменяет все       │
│                                                                 условия.                         │
│ --average-cpc                 <float>                           Средняя цена клика, ₽ (стратегия │
│                                                                 с оплатой за клики).             │
│ --average-cpa                 <float>                           Средняя цена конверсии, ₽        │
│                                                                 (стратегия с оплатой за          │
│                                                                 конверсии).                      │
│ --priority                    <LOW|NORMAL|HIGH>                 Приоритет для автостратегии:     │
│                                                                 LOW, NORMAL, HIGH.               │
│ --available-items-only        <YES|NO>                          YES — только товары в наличии.   │
│ --confirm                                                       Подтвердить изменение в кабинете │
│                                                                 без вопроса (обязательно вместе  │
│                                                                 с --non-interactive).            │
│ --dry-run                                                       Показать, что будет сделано,     │
│                                                                 ничего не меняя.                 │
│ --non-interactive                                               Никогда не спрашивать; при       │
│                                                                 нехватке данных — ошибка.        │
│ --json                                                          Машиночитаемый вывод: JSON в     │
│                                                                 stdout.                          │
│ --quiet                                                         Не печатать ничего, кроме        │
│                                                                 данных.                          │
│ --help                                                          Show this message and exit.      │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
