
 Usage: yd changes check [OPTIONS] {timestamp}

 Изменённые и удалённые объекты внутри кампаний, групп или объявлений с момента времени.

 Ровно один вид фильтра: --campaign, --adgroup или --ad (так требует API).
 --json: {"ok": true, "changes": {Modified: {CampaignIds, AdGroupIds, AdIds, CampaignsStat},
 NotFound: {...}, Unprocessed: {...}, Timestamp}}.

 Example: yd changes check 2026-09-01T00:00:00Z --campaign 12345

╭─ Аргументы ──────────────────────────────────────────────────────────────────────────────────────╮
│ *    timestamp      <str>  Момент времени UTC, ISO 8601: 2026-09-01T00:00:00Z. [обязательный]    │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Параметры ──────────────────────────────────────────────────────────────────────────────────────╮
│ --campaign        <int>  Кампания (повторяемая).                                                 │
│ --adgroup         <int>  Группа объявлений (повторяемая).                                        │
│ --ad              <int>  Объявление (повторяемая).                                               │
│ --json                   Машиночитаемый вывод: JSON в stdout.                                    │
│ --quiet                  Не печатать ничего, кроме данных.                                       │
│ --help                   Show this message and exit.                                             │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
