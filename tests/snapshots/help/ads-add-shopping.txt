
 Usage: yd ads add-shopping [OPTIONS]

 Создать товарное объявление по фиду (ShoppingAd, с --listing — ListingAd).

 Фильтры товаров (FeedFilterConditions) — через `ads add-json`.

 Example: yd ads add-shopping --adgroup 555 --feed 7001 --default-text 'Диваны со скидкой'
 --dry-run

╭─ Параметры ──────────────────────────────────────────────────────────────────────────────────────╮
│ *  --adgroup                <int>  Id группы объявлений. [обязательный]                          │
│ *  --feed                   <int>  Id фида товаров. [обязательный]                               │
│ *  --default-text           <str>  Текст по умолчанию (повторяемая). [обязательный]              │
│    --title-source           <str>  Поле фида для заголовка (повторяемая).                        │
│    --text-source            <str>  Поле фида для текста (повторяемая).                           │
│    --sitelink-set           <int>  Id набора быстрых ссылок.                                     │
│    --callout                <int>  Id уточнения (повторяемая).                                   │
│    --business               <int>  Id организации из Яндекс Бизнеса.                             │
│    --listing                       Создать ListingAd (каталог) вместо ShoppingAd.                │
│    --confirm                       Подтвердить изменение в кабинете без вопроса (обязательно     │
│                                    вместе с --non-interactive).                                  │
│    --dry-run                       Показать, что будет сделано, ничего не меняя.                 │
│    --non-interactive               Никогда не спрашивать; при нехватке данных — ошибка.          │
│    --json                          Машиночитаемый вывод: JSON в stdout.                          │
│    --quiet                         Не печатать ничего, кроме данных.                             │
│    --help                          Show this message and exit.                                   │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
