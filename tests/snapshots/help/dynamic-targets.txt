
 Usage: yd dynamic-targets [OPTIONS] COMMAND [ARGS]...

 Нацеливание динамических объявлений по страницам сайта: условия и ставки.

╭─ Параметры ──────────────────────────────────────────────────────────────────────────────────────╮
│ --help          Show this message and exit.                                                      │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Commands ───────────────────────────────────────────────────────────────────────────────────────╮
│ list      Условия нацеливания по страницам сайта: условия, ставки, состояние.                    │
│ add       Добавить условие нацеливания по страницам сайта.                                       │
│ add-json  Добавить условия по страницам из JSON: список WebpageAddItem или {"Webpages": [...]}.  │
│ set-bids  Задать ставки или приоритет условиям по страницам (ровно одно из --id, --adgroup,      │
│           --campaign).                                                                           │
│ suspend   Остановить условия нацеливания по страницам.                                           │
│ resume    Возобновить условия нацеливания по страницам.                                          │
│ delete    Удалить условия нацеливания по страницам.                                              │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
