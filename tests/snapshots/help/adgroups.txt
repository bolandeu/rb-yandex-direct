Usage: rb-yandex-direct adgroups [OPTIONS] [COMMAND] [ARGS]...

  Группы объявлений.

Options:
  --help  Show this message and exit.

Commands:
  add                    Создать текстовую группу объявлений.
  delete                 Удалить группы объявлений безвозвратно.
  list                   Список групп объявлений (фильтр по кампаниям и типам).
  set-negative-keywords  Заменить минус-слова на уровне группы (полный список заменяет текущий).
  update                 Обновить группу объявлений (имя, регионы, минус-фразы группы).
