
 Usage: yd adgroups [OPTIONS] COMMAND [ARGS]...

 Группы объявлений: список, создание по типам, изменение, минус-фразы, удаление.

╭─ Параметры ──────────────────────────────────────────────────────────────────────────────────────╮
│ --help          Show this message and exit.                                                      │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Commands ───────────────────────────────────────────────────────────────────────────────────────╮
│ list                   Список групп объявлений с фильтрами по Id, кампании, типу и статусам.     │
│ get                    Одна группа со всеми полями, включая блок её типа (мобильное приложение,  │
│                        фид, домен…).                                                             │
│ add                    Создать группу объявлений; --type задаёт тип и нужные ему опции.          │
│ update                 Изменить группу: название, регионы, минус-фразы, параметры ссылок и поля  │
│                        её типа.                                                                  │
│ set-negative-keywords  Заменить минус-фразы группы: переданный список целиком заменяет текущий.  │
│ delete                 Удалить группы объявлений — необратимо; удаляются только группы без       │
│                        показов.                                                                  │
│ add-json               Создать группы из JSON: список AdGroupAddItem или {"AdGroups": [...]}.    │
│ update-json            Изменить группы из JSON: список AdGroupUpdateItem (с Id) или {"AdGroups": │
│                        [...]}.                                                                   │
