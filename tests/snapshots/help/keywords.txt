Usage: yd keywords [OPTIONS] [COMMAND] [ARGS]...

  Ключевые фразы.

Options:
  --help  Show this message and exit.

Commands:
  add           Добавить ключевые фразы в группу (до 1000 за вызов).
  check-volume  Проверить, есть ли у фраз поисковый спрос.
  dedup         Найти дубли среди переданных ключей и приостановить копии.
  delete        Удалить ключи безвозвратно.
  list          Список ключевых фраз (фильтр по группам, кампаниям, состоянию).
  resume        Возобновить показы по ключевым фразам.
  suspend       Остановить показы по ключевым фразам.
  update        Обновить ключевую фразу.
