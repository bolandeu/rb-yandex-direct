
 Usage: yd campaigns [OPTIONS] COMMAND [ARGS]...

 Кампании: список, изменение, статусы, бюджет, минус-фразы.

╭─ Параметры ──────────────────────────────────────────────────────────────────────────────────────╮
│ --help          Show this message and exit.                                                      │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Команды ────────────────────────────────────────────────────────────────────────────────────────╮
│ list                   Список кампаний с фильтрами по Id, состоянию и типу.                      │
│ get                    Одна кампания по Id: общие поля (набор как у `campaigns list`).           │
│ suspend                Остановить показы кампаний.                                               │
│ resume                 Возобновить показы остановленных кампаний.                                │
│ archive                Архивировать кампании (должны быть остановлены и без остатка средств).    │
│ unarchive              Вернуть кампании из архива.                                               │
│ delete                 Удалить кампании — необратимо; удалить можно только черновики и кампании  │
│                        без показов.                                                              │
│ update                 Изменить общие параметры кампании: название, даты, дневной бюджет.        │
│ set-budget             Задать дневной бюджет кампании в рублях.                                  │
│ set-negative-keywords  Заменить минус-фразы кампании: переданный список целиком заменяет         │
│                        текущий.                                                                  │
│ add-json               Создать кампании из JSON: список CampaignAddItem или {"Campaigns":        │
│                        [...]}.                                                                   │
│ update-json            Изменить кампании из JSON: список CampaignUpdateItem (с Id) или           │
│                        {"Campaigns": [...]}.                                                     │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
