Usage: yd campaigns [OPTIONS] [COMMAND] [ARGS]...

  Управление кампаниями.

Options:
  --help  Show this message and exit.

Commands:
  add-json               Создать кампании из JSON-файла (сложная структура — смотри доку...
  archive                Архивировать.
  delete                 Удалить кампании безвозвратно (должны быть archived).
  list                   Список кампаний с фильтром по состоянию и типу.
  resume                 Возобновить приостановленные кампании.
  set-budget             Задать дневной бюджет кампании в рублях.
  set-negative-keywords  Заменить минус-слова на уровне кампании (полный список заменяет текущий).
  suspend                Приостановить кампании.
  unarchive              Вернуть кампании из архива.
  update                 Обновить параметры кампании (имя, даты, бюджет).
