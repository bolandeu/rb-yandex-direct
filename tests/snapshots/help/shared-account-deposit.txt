
 Usage: yd shared-account deposit [OPTIONS]

 ДЕНЬГИ: пополнить общие счета из кредита агентства или овердрафта (AccountManagement Deposit).

 Суммы — с НДС клиента. Нужен мастер-токен.

 Example: yd shared-account deposit --pay 555=10000 --dry-run

╭─ Параметры ──────────────────────────────────────────────────────────────────────────────────────╮
│ *  --pay                    <str>  Счёт и сумма: ACCOUNT_ID=СУММА (повторяемая, до 50).          │
│                                    [обязательный]                                                │
│    --contract               <str>  Договор кредита агентства; нет — овердрафт рекламодателя.     │
│    --currency               <str>  Валюта сумм: RUB, BYN, KZT, TRY, UAH, USD, EUR, CHF.          │
│                                    [по умолчанию: RUB]                                           │
│    --confirm                       Подтвердить изменение в кабинете без вопроса (обязательно     │
│                                    вместе с --non-interactive).                                  │
│    --dry-run                       Показать, что будет сделано, ничего не меняя.                 │
│    --non-interactive               Никогда не спрашивать; при нехватке данных — ошибка.          │
│    --json                          Машиночитаемый вывод: JSON в stdout.                          │
│    --quiet                         Не печатать ничего, кроме данных.                             │
│    --help                          Show this message and exit.                                   │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
