
 Usage: yd clients list [OPTIONS]

 Параметры кабинета (clients.get): для агентства — его клиенты.

 Example: yd clients list --field Login --field Currency --json

│ --json                Машиночитаемый вывод: JSON в stdout.                                       │
│ --quiet               Не печатать ничего, кроме данных.                                          │
│ --help                Show this message and exit.                                                │
