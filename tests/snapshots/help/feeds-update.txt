
 Usage: yd feeds update [OPTIONS] {feed_id}

 Изменить фид: название, ссылку и её авторизацию, UTM, или загрузить новый файл.

 Тип источника (ссылка/файл) у фида не меняется.

 Example: yd feeds update 7001 --url https://example.com/feed-v2.xml --dry-run

╭─ Аргументы ──────────────────────────────────────────────────────────────────────────────────────╮
│ *    feed_id      <int>  Id фида. [обязательный]                                                 │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Параметры ──────────────────────────────────────────────────────────────────────────────────────╮
│ --name                             <str>  Новое название.                                        │
│ --url                              <str>  Ссылка на фид (фид по ссылке Директ обновляет сам).    │
│ --file                             <str>  Файл фида (XML/YML/CSV) — загружается целиком.         │
│ --feed-login                       <str>  Логин HTTP-авторизации для ссылки на фид.              │
│ --feed-password                    <str>  Пароль HTTP-авторизации для ссылки (лучше через        │
│                                           YANDEX_DIRECT_FEED_PASSWORD, не в истории shell).      │
│                                           [env var: YANDEX_DIRECT_FEED_PASSWORD]                 │
│ --remove-utm         --keep-utm           Убирать ли UTM-метки из ссылок фида (RemoveUtmTags).   │
│ --confirm                                 Подтвердить изменение в кабинете без вопроса           │
│                                           (обязательно вместе с --non-interactive).              │
│ --dry-run                                 Показать, что будет сделано, ничего не меняя.          │
│ --non-interactive                         Никогда не спрашивать; при нехватке данных — ошибка.   │
│ --json                                    Машиночитаемый вывод: JSON в stdout.                   │
│ --quiet                                   Не печатать ничего, кроме данных.                      │
│ --help                                    Show this message and exit.                            │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
