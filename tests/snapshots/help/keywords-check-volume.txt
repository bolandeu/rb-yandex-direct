
 Usage: yd keywords check-volume [OPTIONS] [phrases]...

 Есть ли у фраз поисковый спрос — по всем устройствам, телефонам, планшетам, компьютерам.

 Только чтение (keywordsresearch.hasSearchVolume), кабинет не меняется.
 --json: {"ok": true, "count": N, "keywords": [{Keyword, RegionIds, AllDevices, MobilePhones,
 Tablets, Desktops}]}; значения YES/NO.

 Example: yd keywords check-volume 'купить диван' 'диван недорого' --region 213

╭─ Аргументы ──────────────────────────────────────────────────────────────────────────────────────╮
│   phrases      <str>  Фразы для проверки (или --from-file).                                      │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Параметры ──────────────────────────────────────────────────────────────────────────────────────╮
│ --from-file        <str>  Файл с фразами, по одной в строке.                                     │
│ --region           <int>  Регион Яндекса (213 — Москва, 2 — СПб; по умолчанию 225 — Россия),     │
│                           повторяемая.                                                           │
│ --json                    Машиночитаемый вывод: JSON в stdout.                                   │
│ --quiet                   Не печатать ничего, кроме данных.                                      │
│ --help                    Show this message and exit.                                            │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
