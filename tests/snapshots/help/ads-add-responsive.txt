
 Usage: yd ads add-responsive [OPTIONS]

 Создать адаптивное объявление (ResponsiveAd): Директ сам комбинирует заголовки, тексты и картинки.

 Example: yd ads add-responsive --adgroup 555 --title 'Диваны' --title 'Диваны от 9990 ₽' --text
 'Доставка за день' --href https://example.com --dry-run

╭─ Параметры ──────────────────────────────────────────────────────────────────────────────────────╮
│ *  --adgroup                 <int>  Id группы объявлений. [обязательный]                         │
│ *  --title                   <str>  Вариант заголовка (повторяемая). [обязательный]              │
│ *  --text                    <str>  Вариант текста (повторяемая). [обязательный]                 │
│    --href                    <str>  Ссылка на сайт.                                              │
│    --image-hash              <str>  Хэш изображения (повторяемая).                               │
│    --video-extension         <int>  Id видеодополнения (повторяемая).                            │
│    --display-url-path        <str>  Отображаемый путь ссылки.                                    │
│    --sitelink-set            <int>  Id набора быстрых ссылок.                                    │
│    --callout                 <int>  Id уточнения (повторяемая).                                  │
│    --business                <int>  Id организации из Яндекс Бизнеса.                            │
│    --age-label               <str>  Возрастная метка: AGE_0…AGE_18 или MONTHS_0…MONTHS_12.       │
│    --erir-description        <str>  Описание объекта рекламы для ЕРИР.                           │
│    --confirm                        Подтвердить изменение в кабинете без вопроса (обязательно    │
│                                     вместе с --non-interactive).                                 │
│    --dry-run                        Показать, что будет сделано, ничего не меняя.                │
│    --non-interactive                Никогда не спрашивать; при нехватке данных — ошибка.         │
│    --json                           Машиночитаемый вывод: JSON в stdout.                         │
│    --quiet                          Не печатать ничего, кроме данных.                            │
│    --help                           Show this message and exit.                                  │
