Usage: rb-yandex-direct modifiers add [OPTIONS]

  Добавить корректировку ставки.

  Примеры:   rb-yandex-direct modifiers add --campaign 123 --type MOBILE --value 80   rb-yandex-
  direct modifiers add --adgroup 456 --type DEMOGRAPHICS --gender GENDER_MALE --age AGE_25_34
  --value 120   rb-yandex-direct modifiers add --campaign 123 --type REGIONAL --region 213 --value
  150

  Example: rb-yandex-direct modifiers add --campaign 12345 --type MOBILE --value 50

Options:
  --campaign INTEGER              применить к кампании (исключает --adgroup)
  --adgroup INTEGER               применить к группе (исключает --campaign)
  --type [MOBILE|DESKTOP|DEMOGRAPHICS|RETARGETING|REGIONAL|VIDEO|INCOME_GRADE]
                                  тип корректировки (шорткат без _ADJUSTMENT)  [required]
  --value INTEGER                 процент ставки: 0-1200 (100 = без корректировки, 0 = выключить
                                  показы)  [required]
  --gender [GENDER_MALE|GENDER_FEMALE]
                                  для --type=DEMOGRAPHICS
  --age TEXT                      для --type=DEMOGRAPHICS: AGE_0_17, AGE_18_24, AGE_25_34,
                                  AGE_35_44, AGE_45_54, AGE_55
  --region INTEGER                для --type=REGIONAL
  --retargeting INTEGER           для --type=RETARGETING
  --grade TEXT                    для --type=INCOME_GRADE: HIGHEST | HIGH | ABOVE_AVERAGE | ...
  -y, --yes                       без подтверждения
  --help                          Show this message and exit.
