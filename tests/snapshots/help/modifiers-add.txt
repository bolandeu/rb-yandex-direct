
 Usage: yd modifiers add [OPTIONS]

 Добавить корректировку ставки на кампанию или группу.


 Ещё примеры:
   yd modifiers add --adgroup 456 --type DEMOGRAPHICS --gender GENDER_MALE --age AGE_25_34 --value
 120
   yd modifiers add --campaign 123 --type REGIONAL --region 213 --value 150
   yd modifiers add --campaign 123 --type MOBILE --os IOS --value 80

 Example: yd modifiers add --campaign 12345 --type MOBILE --value 50 --dry-run

╭─ Параметры ──────────────────────────────────────────────────────────────────────────────────────╮

│                             DESKTOP_ONLY|DEMOGRAPHICS|RETARG                                     │
│                             ETING|REGIONAL|VIDEO|SMART_AD|SE                                     │
│                             RP_LAYOUT|INCOME_GRADE|AD_GROUP>                                     │
│ *  --value                  <int>                             Процент ставки: 100 — без          │

│    --adgroup                <int>                             Группа объявлений (или             │
│                                                               --campaign).                       │
│    --os                     <IOS|ANDROID>                     MOBILE/TABLET: только IOS или      │
│                                                               ANDROID.                           │
│    --gender                 <GENDER_MALE|GENDER_FEMALE>       DEMOGRAPHICS: пол.                 │
