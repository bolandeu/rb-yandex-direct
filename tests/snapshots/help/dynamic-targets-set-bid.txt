Usage: yd dynamic-targets set-bid [OPTIONS]

  Установить ставки на условии таргетинга DynamicTextAd.

  Example: yd dynamic-targets set-bid --id 8001 --bid 10

Options:
  --id INTEGER                  ID условия таргетинга  [required]
  --bid FLOAT                   ставка поиск, рубли
  --context-bid FLOAT           ставка в сетях, рубли
  --priority [LOW|NORMAL|HIGH]  приоритет для автостратегии
  -y, --yes                     без подтверждения
  --help                        Show this message and exit.
