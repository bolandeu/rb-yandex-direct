
 Usage: yd suggest [OPTIONS] {keywords}...

 Подсказать похожие ключевые фразы (API v4 GetKeywordsSuggestion, до 20 штук).

 Расходует баллы API. --json: {"ok": true, "count": N, "keywords": ["...", ...]}.

 Example: yd suggest 'купить диван' --json

╭─ Аргументы ──────────────────────────────────────────────────────────────────────────────────────╮
│ *    keywords      <str>  Исходные фразы. [обязательный]                                         │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Параметры ──────────────────────────────────────────────────────────────────────────────────────╮
│ --json           Машиночитаемый вывод: JSON в stdout.                                            │
│ --quiet          Не печатать ничего, кроме данных.                                               │
│ --help           Show this message and exit.                                                     │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
