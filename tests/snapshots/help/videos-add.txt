
 Usage: yd videos add [OPTIONS]

 Загрузить видео; его Id — для `creatives add-video-extension`.

 --json: отчёт изменения; Id видео — в result.AddResults[].Id.

 Example: yd videos add --url https://example.com/promo.mp4 --name Промо --dry-run

╭─ Параметры ──────────────────────────────────────────────────────────────────────────────────────╮
│ --url                    <str>  Ссылка на видеофайл (нужна она или --file).                      │
│ --file                   <str>  Локальный видеофайл.                                             │
│ --name                   <str>  Название видео (по умолчанию — имя файла).                       │
│ --confirm                       Подтвердить изменение в кабинете без вопроса (обязательно вместе │
│                                 с --non-interactive).                                            │
│ --dry-run                       Показать, что будет сделано, ничего не меняя.                    │
│ --non-interactive               Никогда не спрашивать; при нехватке данных — ошибка.             │
│ --json                          Машиночитаемый вывод: JSON в stdout.                             │
│ --quiet                         Не печатать ничего, кроме данных.                                │
│ --help                          Show this message and exit.                                      │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
