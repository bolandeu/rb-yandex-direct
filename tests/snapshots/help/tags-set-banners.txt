
 Usage: yd tags set-banners [OPTIONS]

 Назначить объявлениям метки кампании (UpdateBannersTags): прежние, не перечисленные, снимаются.

 Id меток — из `tags campaigns`.

 Example: yd tags set-banners --banner 777 --tag-id 16590 --dry-run

╭─ Параметры ──────────────────────────────────────────────────────────────────────────────────────╮
│ *  --banner                 <int>  Id объявления (повторяемая). [обязательный]                   │
│    --tag-id                 <int>  Id метки кампании (повторяемая); нет — снять все.             │
│    --confirm                       Подтвердить изменение в кабинете без вопроса (обязательно     │
│                                    вместе с --non-interactive).                                  │
│    --dry-run                       Показать, что будет сделано, ничего не меняя.                 │
│    --non-interactive               Никогда не спрашивать; при нехватке данных — ошибка.          │
│    --json                          Машиночитаемый вывод: JSON в stdout.                          │
│    --quiet                         Не печатать ничего, кроме данных.                             │
│    --help                          Show this message and exit.                                   │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
