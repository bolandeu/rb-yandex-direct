
 Usage: yd wordstat run [OPTIONS] {phrases}...

 Всё сразу: создать отчёт, дождаться готовности, получить и удалить с сервера.

 --json — как у `wordstat get`. Расходует баллы API (до 1000 фраз в сутки).

 Example: yd wordstat run 'купить диван' -r 213 --json

╭─ Аргументы ──────────────────────────────────────────────────────────────────────────────────────╮
│ *    phrases      <str>  Ключевые фразы (до 10), можно с минус-словами: 'диван -кожаный'.        │
│                          [обязательный]                                                          │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Параметры ──────────────────────────────────────────────────────────────────────────────────────╮
│ --region   -r      <int>    Id региона (повторяемая); минус — исключить: -r 1 -r -219. Нет — все │
│                             регионы.                                                             │
│ --timeout          <float>  Сколько секунд ждать готовности отчёта. [по умолчанию: 120.0]        │
│ --keep                      Не удалять отчёт с сервера после получения.                          │
│ --json                      Машиночитаемый вывод: JSON в stdout.                                 │
│ --quiet                     Не печатать ничего, кроме данных.                                    │
│ --help                      Show this message and exit.                                          │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
