
 Usage: yd adgroups get [OPTIONS] {adgroup_id}

 Одна группа со всеми полями, включая блок её типа (мобильное приложение, фид, домен…).

 --json: {"ok": true, "adgroup": {...}}; нет такой группы — INVALID_ARGUMENTS.

 Example: yd adgroups get 555 --json

╭─ Аргументы ──────────────────────────────────────────────────────────────────────────────────────╮
│ *    adgroup_id      <int>  Id группы. [обязательный]                                            │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Параметры ──────────────────────────────────────────────────────────────────────────────────────╮
│ --json           Машиночитаемый вывод: JSON в stdout.                                            │
│ --quiet          Не печатать ничего, кроме данных.                                               │
│ --help           Show this message and exit.                                                     │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
