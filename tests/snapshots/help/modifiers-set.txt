Usage: yd modifiers set [OPTIONS]

  Изменить значение существующей корректировки.

  Example: yd modifiers set --id 3001 --value 120

Options:
  --id INTEGER     ID корректировки  [required]
  --value INTEGER  0-1200  [required]
  -y, --yes        без подтверждения
  --help           Show this message and exit.
