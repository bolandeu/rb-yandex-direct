
 Usage: yd extensions add [OPTIONS] {texts}...

 Создать уточнения; Id из ответа — для `ads add-text --callout` и `ads update --callout-add`.

 Example: yd extensions add 'Доставка за день' 'Гарантия 2 года' --dry-run

╭─ Аргументы ──────────────────────────────────────────────────────────────────────────────────────╮
│ *    texts      <str>  Тексты уточнений, каждый до 25 символов. [обязательный]                   │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Параметры ──────────────────────────────────────────────────────────────────────────────────────╮
│ --confirm                  Подтвердить изменение в кабинете без вопроса (обязательно вместе с    │
│                            --non-interactive).                                                   │
│ --dry-run                  Показать, что будет сделано, ничего не меняя.                         │
│ --non-interactive          Никогда не спрашивать; при нехватке данных — ошибка.                  │
│ --json                     Машиночитаемый вывод: JSON в stdout.                                  │
│ --quiet                    Не печатать ничего, кроме данных.                                     │
│ --help                     Show this message and exit.                                           │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
