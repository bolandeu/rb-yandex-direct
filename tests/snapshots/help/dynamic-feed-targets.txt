
 Usage: yd dynamic-feed-targets [OPTIONS] COMMAND [ARGS]...

 Нацеливание динамических объявлений по фиду: фильтры товаров и ставки.

╭─ Параметры ──────────────────────────────────────────────────────────────────────────────────────╮
│ --help          Show this message and exit.                                                      │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Команды ────────────────────────────────────────────────────────────────────────────────────────╮
│ list      Фильтры динамических объявлений по фиду: условия по полям товаров, ставки, состояние.  │
│ add       Добавить фильтр динамических объявлений по фиду.                                       │
│ add-json  Добавить фильтры по фиду из JSON: список DynamicFeedAdTargetAddItem или                │
│           {"DynamicFeedAdTargets": [...]}.                                                       │
│ set-bids  Задать ставки фильтрам по фиду (ровно одно из --id, --adgroup, --campaign).            │
│ suspend   Остановить фильтры по фиду.                                                            │
│ resume    Возобновить фильтры по фиду.                                                           │
│ delete    Удалить фильтры по фиду.                                                               │
