
 Usage: yd ads update [OPTIONS] {ad_id}

 Изменить текстовое объявление (TextAd); после изменения оно снова уходит на модерацию.

 Другие типы объявлений — `ads update-json`.

 Example: yd ads update 777 --title 'Диваны от 8990 ₽' --callout-add 1301 --dry-run

╭─ Аргументы ──────────────────────────────────────────────────────────────────────────────────────╮
│ *    ad_id      <int>  Id текстового объявления. [обязательный]                                  │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Параметры ──────────────────────────────────────────────────────────────────────────────────────╮
│ --title                   <str>  Новый заголовок.                                                │
│ --title2                  <str>  Новый второй заголовок.                                         │
│ --text                    <str>  Новый текст.                                                    │
│ --href                    <str>  Новая ссылка.                                                   │
│ --display-url-path        <str>  Новый отображаемый путь.                                        │
│ --image-hash              <str>  Новое изображение; пустая строка — убрать.                      │
│ --sitelink-set            <int>  Id набора быстрых ссылок.                                       │
│ --vcard                   <int>  Id визитки.                                                     │
│ --turbo                   <int>  Id турбо-страницы.                                              │
│ --callout-add             <int>  Добавить уточнение (повторяемая).                               │
│ --callout-remove          <int>  Убрать уточнение (повторяемая).                                 │
│ --callout-set             <int>  Заменить уточнения этими (повторяемая).                         │
│ --erir-description        <str>  Описание объекта рекламы для ЕРИР.                              │
│ --confirm                        Подтвердить изменение в кабинете без вопроса (обязательно       │
│                                  вместе с --non-interactive).                                    │
│ --dry-run                        Показать, что будет сделано, ничего не меняя.                   │
│ --non-interactive                Никогда не спрашивать; при нехватке данных — ошибка.            │
│ --json                           Машиночитаемый вывод: JSON в stdout.                            │
│ --quiet                          Не печатать ничего, кроме данных.                               │
│ --help                           Show this message and exit.                                     │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
