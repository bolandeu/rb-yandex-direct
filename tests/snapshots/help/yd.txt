Usage: yd [OPTIONS] [COMMAND] [ARGS]...

  Яндекс.Директ API v5 — CLI.

Options:
  --version           Show the version and exit.
  --login TEXT        Client-Login (логин рекламодателя для агентского доступа)
  --sandbox / --prod  Переключить окружение для этого вызова
  -v, --verbose       Подробные логи
  --help              Show this message and exit.

Commands:
  accounts         Кабинеты, к которым есть доступ (представитель/агентство).
  adgroups         Группы объявлений.
  ads              Объявления.
  audiences        Привязки аудиторий к группам объявлений.
  auth             OAuth-токен Директа: вход, статус, обновление, выход.
  bids             Ставки по ключевым фразам.
  businesses       Список бизнес-данных (Яндекс.Бизнес).
  campaigns        Управление кампаниями.
  changes          Синхронизация изменений (changes.* API).
  client           Настройки одного клиента (clients.update / agencyclients.update).
  clients          Список клиентов агентства (или себя для обычного аккаунта).
  creatives        Креативы (HTML5/видео/смарт-баннеры) — только чтение.
  dict             Справочники: регионы, валюты, таймзоны, категории.
  dynamic-targets  Условия таргетинга для динамических объявлений.
  extensions       Уточнения объявлений (callouts).
  feeds            Товарные фиды.
  images           Изображения для объявлений (adimages).
  keywords         Ключевые фразы.
  leads            Лиды с lead-форм и Турбо-страниц.
  minus-sets       Общие наборы минус-слов.
  modifiers        Корректировки ставок (устройства, регионы, демо, ретаргетинг).
  report           Отчёты v5 (TSV, polling).
  retargeting      Списки ретаргетинга (цели/аудитории Метрики).
  sitelinks        Наборы быстрых ссылок.
  smart-targets    Условия таргетинга для смарт-баннеров.
  turbo            Турбо-страницы.
  vcards           Визитки (контактная информация).
  whoami           Проверить токен и показать клиентов (clients.get).
