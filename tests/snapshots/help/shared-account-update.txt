
 Usage: yd shared-account update [OPTIONS] {account_id}

 Изменить настройки общего счёта: дневной бюджет и почтовые уведомления (AccountManagement Update).

 Дневной бюджет можно менять не чаще 3 раз в сутки. Не указанное не меняется.

 Example: yd shared-account update 555 --day-budget 3000 --dry-run

╭─ Аргументы ──────────────────────────────────────────────────────────────────────────────────────╮
│ *    account_id      <int>  Id общего счёта. [обязательный]                                      │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Параметры ──────────────────────────────────────────────────────────────────────────────────────╮
│ --day-budget                               <float>  Дневной бюджет в валюте счёта; 0 — снять.    │
│ --email                                    <str>    Почта для уведомлений.                       │
│ --money-warning                            <int>    Порог уведомления об остатке, % (1–50).      │
│ --notify-paused      --no-notify-paused             Письмо при остановке по дневному бюджету.    │
│ --confirm                                           Подтвердить изменение в кабинете без вопроса │
│                                                     (обязательно вместе с --non-interactive).    │
│ --dry-run                                           Показать, что будет сделано, ничего не       │
│                                                     меняя.                                       │
│ --non-interactive                                   Никогда не спрашивать; при нехватке данных — │
│                                                     ошибка.                                      │
│ --json                                              Машиночитаемый вывод: JSON в stdout.         │
│ --quiet                                             Не печатать ничего, кроме данных.            │
│ --help                                              Show this message and exit.                  │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
