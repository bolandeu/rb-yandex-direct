
 Usage: yd masters get [OPTIONS] {campaign_id}

 Одна кампания Мастера: название, статус, ссылка, плитки статистики (для черновика — поля формы).

 --json: {"ok": true, "master": {CampaignId, Name, Status, LandingUrl, …}}.

 Example: yd masters get 72349978 --tracking-params --json

╭─ Аргументы ──────────────────────────────────────────────────────────────────────────────────────╮
│ *    campaign_id      <int>  Id кампании Мастера (как в интерфейсе Директа). [обязательный]      │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Параметры ──────────────────────────────────────────────────────────────────────────────────────╮
│ --moderation                    Добавить статусы модерации объявлений.                           │
│ --tracking-params               Добавить UTM-метки (параметры ссылки).                           │
│ --headful                       Показать окно браузера (отладка, капча).                         │
│ --chrome-dir             <str>  Папка профилей Chrome (user-data-dir): всегда свежие куки        │
│                                 оттуда, без сохранённой сессии.                                  │
│ --chrome-profile         <str>  Профиль Chrome внутри --chrome-dir. [по умолчанию: Default]      │
│ --json                          Машиночитаемый вывод: JSON в stdout.                             │
│ --quiet                         Не печатать ничего, кроме данных.                                │
│ --help                          Show this message and exit.                                      │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
