
 Usage: yd goals stat [OPTIONS]

 Цели Метрики, доступные в статистике кампаний (GetStatGoals).

 Их Id — для `--goal` отчётов и стратегий с оплатой за конверсии.
 --json: {"ok": true, "count": N, "goals": [{GoalID, Name, CampaignID?}]}.

 Example: yd goals stat --campaign 12345 --json

╭─ Параметры ──────────────────────────────────────────────────────────────────────────────────────╮
│ *  --campaign        <int>  Id кампании (повторяемая). [обязательный]                            │
│    --json                   Машиночитаемый вывод: JSON в stdout.                                 │
│    --quiet                  Не печатать ничего, кроме данных.                                    │
│    --help                   Show this message and exit.                                          │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
