
 Usage: yd dynamic-feed-targets set-bids [OPTIONS]

 Задать ставки фильтрам по фиду (ровно одно из --id, --adgroup, --campaign).

 Example: yd dynamic-feed-targets set-bids --id 8101 --bid 10 --dry-run

╭─ Параметры ──────────────────────────────────────────────────────────────────────────────────────╮
│ --id                     <int>    Id условия.                                                    │
│ --adgroup                <int>    Id группы — для всех её условий.                               │
│ --campaign               <int>    Id кампании — для всех её условий.                             │
│ --bid                    <float>  Ставка на поиске, ₽.                                           │
│ --context-bid            <float>  Ставка в сетях, ₽.                                             │
│ --confirm                         Подтвердить изменение в кабинете без вопроса (обязательно      │
│                                   вместе с --non-interactive).                                   │
│ --dry-run                         Показать, что будет сделано, ничего не меняя.                  │
│ --non-interactive                 Никогда не спрашивать; при нехватке данных — ошибка.           │
│ --json                            Машиночитаемый вывод: JSON в stdout.                           │
│ --quiet                           Не печатать ничего, кроме данных.                              │
│ --help                            Show this message and exit.                                    │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
