
 Usage: yd ads add-json [OPTIONS]

 Создать объявления из JSON: список AdAddItem или {"Ads": [...]} — любой тип, до 1000 за вызов.

 У каждого — AdGroupId и ровно один блок типа (TextAd, ResponsiveAd, MobileAppAd,
 SmartAdBuilderAd…).

 Example: yd ads add-json --from-json ads.json --dry-run

╭─ Параметры ──────────────────────────────────────────────────────────────────────────────────────╮
│ *  --from-json              <str>  JSON-файл с параметрами метода API (как в документации        │
│                                    Директа); `-` — stdin.                                        │
│                                    [обязательный]                                                │
│    --confirm                       Подтвердить изменение в кабинете без вопроса (обязательно     │
│                                    вместе с --non-interactive).                                  │
│    --dry-run                       Показать, что будет сделано, ничего не меняя.                 │
│    --non-interactive               Никогда не спрашивать; при нехватке данных — ошибка.          │
│    --json                          Машиночитаемый вывод: JSON в stdout.                          │
│    --quiet                         Не печатать ничего, кроме данных.                             │
│    --help                          Show this message and exit.                                   │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
