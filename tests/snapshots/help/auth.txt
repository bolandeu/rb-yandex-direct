
 Usage: yd auth [OPTIONS] COMMAND [ARGS]...

 OAuth-токен Директа: вход, статус, обновление, выход. Токен — в keychain ОС (yandex-oauth:direct)
 и обновляется сам; без keychain — YANDEX_OAUTH_DIRECT_REFRESH_TOKEN/CLIENT_ID/CLIENT_SECRET или
 готовый YANDEX_DIRECT_TOKEN. Файлы .env не читаются.

╭─ Параметры ──────────────────────────────────────────────────────────────────────────────────────╮
│ --help          Show this message and exit.                                                      │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Commands ───────────────────────────────────────────────────────────────────────────────────────╮
│ login    Получить OAuth-токен Директа и сохранить в keychain вместе с refresh_token.             │
│ refresh  Принудительно обновить токен по refresh_token (без браузера).                           │
│ logout   Удалить токен и данные приложения из keychain (переменные окружения не трогает).        │
│ status   Откуда берётся токен и работает ли он. Значений секретов не печатает.                   │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
