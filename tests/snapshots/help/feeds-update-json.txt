Usage: rb-yandex-direct feeds update-json [OPTIONS]

  Обновить фиды из JSON-файла.

  Example: rb-yandex-direct feeds update-json --from-json feeds.json

Options:
  --from-json PATH  JSON-массив объектов фидов с полем Id  [required]
  -y, --yes         без подтверждения
  --help            Show this message and exit.
