Usage: yd ads list [OPTIONS]

  Список объявлений (фильтр по кампаниям, группам, состоянию, статусу).

  Example: yd ads list --campaign 12345 --status REJECTED

Options:
  --campaign INTEGER              фильтр по кампании (можно несколько раз)
  --adgroup INTEGER               фильтр по группе объявлений (можно несколько раз)
  --state [ON|OFF|SUSPENDED|OFF_BY_MONITORING|ARCHIVED]
                                  фильтр по состоянию (можно несколько раз)
  --status [ACCEPTED|DRAFT|MODERATION|PREACCEPTED|REJECTED|UNKNOWN]
                                  фильтр по статусу модерации (можно несколько раз)
  --output PATH                   сохранить JSON в файл
  --help                          Show this message and exit.
