
 Usage: yd finance setup [OPTIONS]

 Сохранить мастер-токен финансовых операций и логин в keychain (yandex-oauth:direct_finance).

 Мастер-токен выдаётся один раз: Директ → Настройки API → Финансовые операции →
 «Разрешить финансовые операции» → «Выдать новый мастер-токен» (подтверждение по SMS).
 Без keychain (сервер) — env YANDEX_OAUTH_DIRECT_FINANCE_MASTER_TOKEN и
 YANDEX_OAUTH_DIRECT_FINANCE_LOGIN, setup не нужен. Токен в аргументах не принимается.

 Example: yd finance setup --finance-login agency-login

╭─ Параметры ──────────────────────────────────────────────────────────────────────────────────────╮
│ --finance-login             <str>  Логин, от имени которого идут финансовые вызовы (владелец     │
│                                    OAuth-токена).                                                │
│ --master-token-stdin               Прочитать мастер-токен из stdin (скрипты); иначе — скрытый    │
│                                    ввод.                                                         │
│ --non-interactive                  Никогда не спрашивать; при нехватке данных — ошибка.          │
│ --json                             Машиночитаемый вывод: JSON в stdout.                          │
│ --quiet                            Не печатать ничего, кроме данных.                             │
│ --help                             Show this message and exit.                                   │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
