
 Usage: yd changes campaigns [OPTIONS] {timestamp}

 Какие кампании менялись с момента времени: сами (SELF), их содержимое (CHILDREN), статистика
 (STAT).

 Первый шаг синхронизации: дальше `changes check --campaign …` по изменившимся.
 --json: {"ok": true, "count": N, "campaigns": [{CampaignId, ChangesIn: [...]}], "timestamp":
 "<новая точка отсчёта>"}.

 Example: yd changes campaigns 2026-09-01T00:00:00Z --json

╭─ Аргументы ──────────────────────────────────────────────────────────────────────────────────────╮
│ *    timestamp      <str>  Момент времени UTC, ISO 8601: 2026-09-01T00:00:00Z. [обязательный]    │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Параметры ──────────────────────────────────────────────────────────────────────────────────────╮
│ --json           Машиночитаемый вывод: JSON в stdout.                                            │
│ --quiet          Не печатать ничего, кроме данных.                                               │
│ --help           Show this message and exit.                                                     │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
