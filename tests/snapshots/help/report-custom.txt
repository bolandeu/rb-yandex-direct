
 Usage: yd report custom [OPTIONS]

 Произвольный отчёт: любой тип, поля, фильтры, сортировка, цели и модели атрибуции.

 Какие поля допустимы в каком типе — в документации Reports (fields-list);
 несовместимые поля API отвергает кодом 4000. --json: как у `report campaigns`.


 Ещё примеры:
   yd report custom --type CRITERIA_PERFORMANCE_REPORT --field Criterion --field Clicks --field
 Cost --range LAST_7_DAYS --filter Clicks:GREATER_THAN:0 --order-by Cost:DESC --limit 50

 Example: yd report custom --type CUSTOM_REPORT --date-from 2026-09-01 --date-to 2026-09-27 --field
 Date --field Clicks --field Cost
