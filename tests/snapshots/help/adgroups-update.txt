Usage: yd adgroups update [OPTIONS] ADGROUP_ID

  Обновить группу объявлений (имя, регионы, минус-фразы группы).

  Example: yd adgroups update 555 --name 'Диваны Москва'

Options:
  --name TEXT              новое имя группы
  --region INTEGER         ID региона (можно несколько раз; заменяет весь список)
  --negative-keyword TEXT  минус-фраза группы (можно несколько раз; заменяет весь список)
  -y, --yes                без подтверждения
  --help                   Show this message and exit.
