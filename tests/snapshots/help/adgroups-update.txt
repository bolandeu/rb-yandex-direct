
 Usage: yd adgroups update [OPTIONS] {adgroup_id}

 Изменить группу: название, регионы, минус-фразы, параметры ссылок и поля её типа.

 Списки (регионы, минус-фразы, наборы) заменяются целиком. Остальное — `adgroups update-json`.

 Example: yd adgroups update 555 --name 'Диваны Москва' --region 213 --dry-run

╭─ Аргументы ──────────────────────────────────────────────────────────────────────────────────────╮
│ *    adgroup_id      <int>  Id группы. [обязательный]                                            │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Параметры ──────────────────────────────────────────────────────────────────────────────────────╮
│ --name                     <str>     Новое название.                                             │
│ --region                   <int>     Id региона (повторяемая; заменяет весь список).             │
│ --negative-keyword         <str>     Минус-фраза (повторяемая; заменяет весь список).            │
│ --minus-set                <int>     Id набора общих минус-фраз (повторяемая; заменяет список).  │
│ --tracking-params          <str>     Параметры к ссылкам; пустая строка — убрать.                │
│ --domain-url               <str>     Динамическая группа: новый домен.                           │
│ --offer-retargeting        <YES|NO>  Группа ЕПК: офферный ретаргетинг.                           │
│ --ad-title-source          <str>     Смарт-группа: поле фида для заголовка.                      │
│ --ad-body-source           <str>     Смарт-группа: поле фида для текста.                         │
│ --confirm                            Подтвердить изменение в кабинете без вопроса (обязательно   │
│                                      вместе с --non-interactive).                                │
│ --dry-run                            Показать, что будет сделано, ничего не меняя.               │
│ --non-interactive                    Никогда не спрашивать; при нехватке данных — ошибка.        │
│ --json                               Машиночитаемый вывод: JSON в stdout.                        │
│ --quiet                              Не печатать ничего, кроме данных.                           │
│ --help                               Show this message and exit.                                 │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
