
 Usage: yd skill install [OPTIONS]

 Скопировать SKILL.md из пакета в папку скиллов AI-инструмента.

 Example: yd skill install --tool claude-code

╭─ Параметры ──────────────────────────────────────────────────────────────────────────────────────╮
│ --tool           <str>  Куда ставить: claude-code, agents. [по умолчанию: claude-code]           │
│ --project               В текущий проект, а не в папку пользователя.                             │
│ --json                  Машиночитаемый вывод: JSON в stdout.                                     │
│ --quiet                 Не печатать ничего, кроме данных.                                        │
│ --help                  Show this message and exit.                                              │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
