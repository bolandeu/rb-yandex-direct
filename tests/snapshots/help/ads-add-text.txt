Usage: rb-yandex-direct ads add-text [OPTIONS]

  Создать одно текстовое объявление (TextAd).

  Example: rb-yandex-direct ads add-text --adgroup 555 --title 'Диваны от 9990 ₽' --text 'Доставка
  за день' --href https://example.com

Options:
  --adgroup INTEGER        ID группы объявлений  [required]
  --title TEXT             первый заголовок (до 56 симв.)  [required]
  --text TEXT              основной текст (до 81 симв.)  [required]
  --href TEXT              URL посадочной страницы  [required]
  --title2 TEXT            второй заголовок
  --display-url-path TEXT  отображаемый путь URL
  --image-hash TEXT        хэш картинки (привязать ad-image)
  --sitelink-set INTEGER   ID набора быстрых ссылок
  --vcard INTEGER          ID визитки
  --turbo INTEGER          ID турбо-страницы
  -y, --yes                без подтверждения
  --help                   Show this message and exit.
