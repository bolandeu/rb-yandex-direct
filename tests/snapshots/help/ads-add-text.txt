
 Usage: yd ads add-text [OPTIONS]

 Создать текстово-графическое объявление (TextAd).

 Example: yd ads add-text --adgroup 555 --title 'Диваны от 9990 ₽' --text 'Доставка за день' --href
 https://example.com --dry-run

│ *  --title                   <str>              Заголовок (до 56 символов). [обязательный]       │
│ *  --text                    <str>              Текст (до 81 символа). [обязательный]            │
│    --href                    <str>              Ссылка на сайт (нужна она или --turbo).          │
│    --title2                  <str>              Второй заголовок (до 30 символов).               │
│    --display-url-path        <str>              Отображаемый путь ссылки (до 20 символов).       │
│    --final-url               <str>              Конечный адрес после редиректов трекера.         │
│    --mobile                  <YES|NO>           Мобильное объявление. [по умолчанию: NO]         │
│    --image-hash              <str>              Хэш изображения (`images add`).                  │
│    --sitelink-set            <int>              Id набора быстрых ссылок.                        │

│    --turbo                   <int>              Id турбо-страницы.                               │
│    --business                <int>              Id организации из Яндекс Бизнеса.                │
│    --callout                 <int>              Id уточнения (повторяемая).                      │
