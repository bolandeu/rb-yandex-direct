# yd

Яндекс.Директ API v5 (+ v4 Live и веб-интерфейс): библиотека rb_yandex_direct и CLI yd

## Словарь

**Проект**:
Каталог с `.rb_yandex_direct/config.toml`, созданный `yd init`; даёт командам настройки по умолчанию.
_Избегать_: workspace, рабочая папка

**Гейт**:
Полная проверка, которую код проходит перед коммитом и релизом: сборка, линтер, типы, тесты и контракты.
_Избегать_: CI, линт
